# CQ-03 — Pending questions in the chat manager

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** CQ-02
- **Plan:** [chat-questions.md](../../plan/chat-questions.md)

## Scope

- `internal/engine/chat.go`: `ChatQuestion {id, toolCallId, message, schema,
  outcome, content}`; pending questions kept like permissions, in
  `ChatState.questions`; updates `question` and `question_resolved`
  (outcome `accept`, `decline`, `cancel` or `withdrawn`).
- `ChatManager.Answer(chatID, questionID, action, content)`: validates against
  the schema; `ErrQuestionNotFound` when it is no longer pending.
- Turn cancel, close, the agent's exit and a withdrawal resolve the question.
- `ChatStartRequest.Questions` (the app shows questions): only then is
  `OnElicitation` set.

## Acceptance and tests

- A question is emitted, listed in the state, answered once, and resolved.
- An invalid answer is refused and the question stays pending.
- Cancel, close, exit and withdrawal resolve it as `cancel`/`withdrawn`.
- Without `Questions` the agent is not offered elicitation.
- `go test -race ./internal/engine/`.
