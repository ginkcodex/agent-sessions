# CQ-03 — Pending questions in the chat manager

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** CQ-02
- **Plan:** [chat-questions.md](../../plan/chat-questions.md)

## Scope

- `internal/engine/chat.go`: `ChatQuestion {id, toolCallId, message, schema,
  outcome, content}`; pending questions kept like permissions, in
  `ChatState.questions`; updates `question` and `question_resolved`
  (outcome `accept`, `decline`, `cancel` or `withdrawn`).
- `ChatManager.Answer(chatID, questionID, action, content)`: validates against
  the schema; `ErrQuestionNotFound` when it is no longer pending.
- Turn cancel, close, the agent's exit and a withdrawal resolve the question.
- `ChatStartRequest.Questions` (the app shows questions): only then is
  `OnElicitation` set.

## Acceptance and tests

- A question is emitted, listed in the state, answered once, and resolved.
- An invalid answer is refused and the question stays pending.
- Cancel, close, exit and withdrawal resolve it as `cancel`/`withdrawn`.
- Without `Questions` the agent is not offered elicitation.
- `go test -race ./internal/engine/`.

## Evidence

Done:

- `ChatQuestion` has `id`, `toolCallId`, `message`, the form's `title` and
  `description`, `fields`, `required`, `meta`, `outcome` and `content`.
  `fields` is a list of `{key, …property}` in the order the agent sent, so
  the frontend never sees a reordered object.
- `ChatState.questions` lists the pending questions oldest first.
- The `question` and `question_resolved` updates carry an outcome of
  `accept`, `decline`, `cancel` or `withdrawn`.
- `ChatManager.Answer(chatID, questionID, action, content)`:
  - checks content with `ElicitationSchema.ValidateValues` (new in
    `internal/acp`), refuses an answer that does not fit and keeps the
    question pending;
  - returns `ErrQuestionNotFound` once the question is answered, cancelled or
    withdrawn.
- A withdrawn question is told apart from a cancelled one by the handler
  context's cause, `acp.ErrWithdrawn`, which `Conn` now sets on
  `$/cancel_request`.
- `ChatStartRequest.Questions` sets `OnElicitation`. Without it, the agent is
  not offered forms.
- Fake agent: `askexit` asks a form and then exits.

Verified:

- `go test -race -count=1 ./internal/engine/ ./internal/acp/...` passed. The
  new tests are:
  - `TestChatQuestionAnswered`: the order of fields in the JSON, the state

  - `TestChatQuestionsNeedTheFlag`;
  - `TestChatCancelAnswersQuestion`, `TestChatCloseDuringQuestion`,
