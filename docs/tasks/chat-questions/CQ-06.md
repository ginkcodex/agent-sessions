# CQ-06 — Question card

- **Status:** ✅ Done
- **Estimate:** 4 h
- **Depends on:** CQ-05
- **Plan:** [chat-questions.md](../../plan/chat-questions.md)

## Scope

- `components/chat/QuestionCard.svelte`, shown with the permission cards:
  header and message; one question, or tabs plus Review; options with
  descriptions; Type your own answer; text, Yes/No and number inputs; checks on
  answered tabs; single choice moves to the next tab; Change from Review;
  Submit (disabled with the reason while a required question is open) and
  Skip; 1–9 and ←/→; no preselection; Enter does not submit.
- The resolved summary line in the live tail.

## Acceptance and tests

- SSR tests: one question, several, each kind, the own answer, Review with
  Change, required, Skip, no preselection.
- `npm test`, `npm run check`, `npm run build`; screenshots in dark and light
  of the three shapes in the user's screenshots.

## Evidence

What was done:

- `components/chat/QuestionCard.svelte`, under the permission cards in the
  live tail: "<Agent> asks" and the agent's message. One question shows on
  its own with Submit and Skip. Several get a tab each (a number, or a check
  once answered without a problem) and a Review tab listing each answer, or
  "Not answered", with a Change link back to its tab. Submit is on Review and
  on the last question, Next on the others.
- Each kind: a single choice and a multi-select as numbered options with
  their descriptions, "(Recommended)" kept as sent and a schema default
  marked "Default"; the own answer as the last numbered row with its box
  (Codex's note, standing for the hidden "Other"); text (a password box for
  Codex's `isSecret`), Yes/No, and a number box with its bounds. Limits show
  under the question as the answer is typed. "Clear answer" takes an answer
  back.
- Choosing an option of a single choice or Yes/No moves to the next tab
  (the last moves to Review); a multi-select stays open. Any answer can
  change until Submit. Nothing is preselected and the card takes no focus.
- Keys: 1–9 pick an option of the open question (the own answer's number
  goes to its box), ← and → move between tabs; keys typed in a box stay text.
  Enter on Submit or in a box sends nothing.
- Submit is disabled while `submitBlocker` gives a reason, and the reason
  shows next to it. Skip answers `decline`. A refused answer keeps the card
  and says why; a stale reply after a host switch is ignored. Codex's
  `autoResolutionMs` shows as "Codex goes on without an answer after about …".
- `chat.ts`: `tailBlocks` gives the tail as messages and answer lines;
  `LiveTail` shows the line ("Answered: …", "Skipped the question", …) where
  it happened, so what the agent says next is a new message. The working
  status says "<Agent> waits for your answer." for a question too.
- `chatOpen` starts every chat with `questions: true` (Open in Chat, a new
  chat, a restart). Icon `circle-help` added. `chatQuestions.ts`: `secret`
  questions read back as "(hidden)" in Review and the summary.
