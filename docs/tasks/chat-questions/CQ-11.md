# CQ-11 — Session text size in the live chat and composer

- **Status:** ✅ Done
- **Estimate:** 1.5 h
- **Depends on:** CQ-10
- **Plan:** [chat-questions.md](../../plan/chat-questions.md)

## Scope

The question and permission cards, the live tail's status, answer and notice
lines, and the composer's text box use `--session-font-size` with the type
scale, so the live chat reads at the same size as the saved messages and
follows Settings → Appearance → Session text size. `TranscriptView` sets the
variable where the composer inherits it too.
