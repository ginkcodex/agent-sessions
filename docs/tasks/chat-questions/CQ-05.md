# CQ-05 — Question model, store and mock

- **Status:** ⬜ Not started
- **Estimate:** 4 h
- **Depends on:** CQ-04
- **Plan:** [chat-questions.md](../../plan/chat-questions.md)

## Scope

- `frontend/src/lib/types.ts` and `api.ts`: `ChatQuestion`, the updates,
  `chatAnswer`, the Wails binding and its cancel-on-close handling.
- `frontend/src/lib/chatQuestions.ts` (pure): schema → questions (kind,
  header, question text, options with descriptions, default, limits,
  required); own-answer pairing for each adapter; the Codex "Other" option
  hidden; a draft; `missing(draft)`; `content(draft)` for each adapter's shape;
  a summary line.
- `stores/chats.svelte.ts`: pending questions per chat from updates and state;
  `answer()`; the summary in the live tail after Submit.
- Mock agent: asks Claude-, Codex- and OpenCode-shaped forms on a keyword, and
  withdraws one.

## Acceptance and tests

- Unit tests for each adapter's shape, pairing, required, limits, content and
  summary; store tests for asked, answered, resolved and withdrawn;
  `npm run check`.
