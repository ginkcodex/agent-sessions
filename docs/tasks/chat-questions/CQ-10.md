# CQ-10 — Modern question card

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** CQ-09
- **Plan:** [chat-questions.md](../../plan/chat-questions.md)

## Scope

Restyle `QuestionCard.svelte` as the plan's "Card look" section describes:
the card surface, the header chip, segmented tabs with number and check
circles, rounded option rows with the shortcut as a keycap at the end, the own
answer row, the footer with a filled primary button and keycaps, and the
Review rows. The permission card takes the same surface and header so both
cards look alike. No change in behavior.

- `frontend/src/lib/components/chat/QuestionCard.svelte`
- `frontend/src/lib/components/chat/PermissionCard.svelte`
- `frontend/test/chat-question-card.test.mjs`
