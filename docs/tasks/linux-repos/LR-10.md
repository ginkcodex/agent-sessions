## Scope

`repo-meta.sh` also fills `"rpm"`: for each `.rpm`, `createrepo_c` on a
folder holding only that file, and the `<package>` element for it from
`primary.xml`, `filelists.xml` and `other.xml`, with `location href` set to
`pool/<version>/<file name>`. Each entry has `arch`, `file`, `size`,
`sha256`, `primary`, `filelists`, `other`.

## Likely files

`packaging/linux/repo-meta.sh`, its test.

## Acceptance criteria and tests

- A repository assembled from these fragments (the LR-12 logic, done here
  with a small script) passes `dnf repoquery` in a Fedora container and
  lists both RPMs.
- The RPMs' signatures, when present, are unchanged by the script.
