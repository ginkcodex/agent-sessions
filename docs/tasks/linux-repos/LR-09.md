## Scope

- `packaging/linux/repo-meta.sh VERSION DIST_DIR`: for each `.deb`, the
  `apt-ftparchive packages` stanza for that one file, `Filename:` set to
  `pool/<version>/<file name>`. Writes `dist/repo-meta.json`:
  `{"version": ..., "deb": [{"arch", "file", "size", "sha256", "stanza"}], "rpm": []}`.
- The release workflow runs it in the linux job and uploads it with the
  packages.
- `packaging/release-checksums.sh` requires `repo-meta.json` in the release
  set and checks that every size and hash in it matches the files.

## Likely files

`packaging/linux/repo-meta.sh`, `packaging/release-checksums.sh`,
`.github/workflows/release.yml`, `Makefile`.

## Acceptance criteria and tests

- Golden test on the two 1.5.5 `.deb` files: the stanzas equal
  `apt-ftparchive`'s for those files, apart from `Filename`.
- `release-checksums.sh` refuses a set without `repo-meta.json`, and one
  whose meta disagrees with a package.
- shellcheck passes.
