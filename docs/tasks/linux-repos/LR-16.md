## Scope

`packaging/linux/verify-repo.sh BASE_URL` runs, in clean containers of
Ubuntu 24.04, Debian 13, newest Ubuntu, Fedora 40 and newest Fedora:

- the documented setup commands, then install;
- `apt policy` / `dnf --showduplicates list` list every expected version;
- install the oldest listed version, then upgrade straight to the newest;
- apt only: keep an old package list, then `apt upgrade` without
  `apt update` and check the download succeeds.

Usable against `wrangler dev`, a preview, or production.
