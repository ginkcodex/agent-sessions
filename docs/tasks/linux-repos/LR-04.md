# LR-04 — GitHub release reader and checks

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** LR-03
- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

Pure functions plus a small GitHub client:

- Read a release by tag (`/repos/ginkcodex/agent-sessions/releases/tags/{tag}`)
  with `GITHUB_TOKEN`; drafts are refused.
- Download `SHA256SUMS`, parse it strictly, and check `repo-meta.json`
  against it. A release without `repo-meta.json` is recorded but not listed
  in the repositories.
- Classify every asset by name into os, arch and kind, using the names
  `make package-linux` produces; other names get kind `other`.

## Likely files

`web/src/server/github.ts`, `web/src/server/assets.ts`, tests beside them.

## Acceptance criteria and tests

- Classification of the 1.5.5 asset list (fixture) matches a golden table.
- A `repo-meta.json` whose hash differs from `SHA256SUMS`, a missing
  `SHA256SUMS`, malformed lines, and a tag that is not semver are each
  refused with a message.
- The client sends a `User-Agent` and the token, and reports rate limiting
  as its own error.
