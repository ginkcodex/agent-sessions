# LR-05 — Ingest endpoint

- **Status:** ⬜ Not started

- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

`POST /api/ingest {"tag": "..."}`:

- Requires `Authorization: Bearer $INGEST_TOKEN`, compared in constant time.
- Reads the release through LR-04 and writes `releases`, `assets` and
  `release_documents` in one transaction.
- Same `SHA256SUMS` and prerelease flag as stored: no-op,
  `200 {"changed": false}`. Either different: replace the release's rows,
  `{"changed": true}`.
- After a change, runs the rebuild hook (a no-op until LR-14). A hook
  failure is reported in the response and logged; the records stay.

## Likely files

`web/src/server/ingest.ts`, `web/src/worker.ts`, tests.

## Acceptance criteria and tests

Against the local Postgres with a fake GitHub:

- Missing or wrong token: 401, nothing written.
- First ingest writes the rows; the second is a no-op; a changed
  `SHA256SUMS`, or a release turned into a pre-release, replaces them.
- A failure halfway (GitHub error after the first asset) leaves no rows.
