# LR-11 — Worker: apt index builder

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** LR-03, LR-09
- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

In `agent-sessions-web`, pure functions from the stored `repo-meta.json`
documents to the unsigned apt files:

- `dists/stable/main/binary-{amd64,arm64}/Packages` and `Packages.gz`,
  newest version first.
- `dists/stable/Release`: `Origin`, `Label`, `Suite: stable`,
  `Codename: stable`, `Components: main`, `Architectures: amd64 arm64`,
  `Date`, `Acquire-By-Hash: yes`, and the `SHA256` list. No `Valid-Until`.
- The `by-hash/SHA256/<hash>` copies of each index.

## Likely files

`web/worker/repo/apt.ts` (and `files.ts`, shared with LR-12), tests.

## Acceptance criteria and tests

- Golden output for two releases' fixture metadata.
- A repository written from them to disk and signed with a test key
  installs the package with `apt` in an Ubuntu container.

## Done

In `agent-sessions-web` 0a3491d:

- `worker/repo/files.ts`: the builders' input (`ListedRelease`: a version
  and its parsed `repo-meta.json`) and output (`RepoFile`: path below the
  site root, content type, bytes); `gzip` with `CompressionStream`, which
  workerd and Node both have; `newestFirst`, which compares versions as
  numbers.
- `worker/repo/apt.ts`: `buildApt(releases, date)` returns `Packages`,
  `Packages.gz` and a `by-hash/SHA256/<hash>` copy of each, for amd64 and
  arm64, and the `Release` text for LR-13 to sign. The paragraphs are the
  ones in `repo-meta.json`, newest version first, a blank line between
  them. `Release` has the fields the scope lists plus `Description`, and
  no `Valid-Until`. With no releases, the `Packages` files are empty and
  `Release` still lists them.
- Fixture: `worker/test/fixtures/repo-meta-v1.5.5.json`, written by
  `make test-repo-meta` from the real 1.5.5 packages. Other versions are
  copies with the version replaced.
- Golden files in `worker/test/golden/apt/`; `UPDATE_GOLDEN=1` rewrites
  them.

- `npm run test:worker`: 20 pass, 5 of them new (`apt.test.ts`):
  - golden `Packages` for 1.5.5 and 1.6.0, per architecture; the `.gz`
    unpacks to the same text;
