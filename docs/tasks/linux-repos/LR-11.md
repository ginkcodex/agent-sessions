- **Status:** ⬜ Not started

## Scope

In `agent-sessions-web`, pure functions from the stored `repo-meta.json`
documents to the unsigned apt files:

- `dists/stable/main/binary-{amd64,arm64}/Packages` and `Packages.gz`,
  newest version first.
- `dists/stable/Release`: `Origin`, `Label`, `Suite: stable`,
  `Codename: stable`, `Components: main`, `Architectures: amd64 arm64`,
  `Date`, `Acquire-By-Hash: yes`, and the `SHA256` list. No `Valid-Until`.
- The `by-hash/SHA256/<hash>` copies of each index.

## Likely files

`web/src/server/repo/apt.ts`, tests.

## Acceptance criteria and tests

- Golden output for two releases' fixture metadata.
- A repository written from them to disk and signed with a test key
  installs the package with `apt` in an Ubuntu container.
