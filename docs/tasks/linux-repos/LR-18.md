- **Status:** 🟡 Partial: key fingerprints wait for the real keys (LR-19)
- **Estimate:** 2 h

- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

- README: Debian/Ubuntu and Fedora install with the repository, beside the
  AUR section; downloading the `.deb`/`.rpm` stays as an option.
- Website (`agent-sessions-web`): the download page's Linux choices and an
  install guide, in English and Vietnamese, with the same commands, key
  fingerprints, and removal steps.
- A downloaded `.rpm`: `dnf install ./file.rpm` works whether or not the key
  is imported. Plain `rpm -i` on rpm 6 (Fedora 45) needs
  `sudo rpm --import <site>/rpm/RPM-GPG-KEY-agent-sessions` first, and
  refuses unsigned packages (LR-08).
- apt users must fetch the keyring again before a repository key's old
  expiry date ([linux-repos-keys.md](../../plan/linux-repos-keys.md),
  Renewal).

## Done

- **README** (this repository): the Install table offers "The apt
  repository" and "The dnf repository" beside the `.deb` and `.rpm` files.
  The Linux section now has, in order:
  - Debian 13+ / Ubuntu 24.04+: the repository commands, how to update, and
    what to do if `apt update` reports an expired or missing key (fetch the
    keyring again: [linux-repos-keys.md](../../plan/linux-repos-keys.md),
    Renewal);
  - Fedora 40+: the `.repo` file and `dnf install`; dnf asks to import the
    keys, and asks again after a key rotation (LR-16's run 2);
  - removing the repository, for both;
  - a downloaded package, with the `dnf install` / `rpm -i` / `rpm --import`
    note and the unsigned older RPMs;
  - Arch, unchanged.
- **Website** (`agent-sessions-web`, English and Vietnamese):
  - the download page's Linux card points to the repository commands;
  - its notes have "Debian and Ubuntu: add the repository", "Fedora: add the
    repository", "Removing the repository" and "Installing a downloaded
    Linux package". The commands use `siteUrl`, the production address,
    on a preview too (seen on the `develop` preview, 2026-11-13);
  - the Getting started guide's install paragraph mentions the
    repositories and links to the download page for the commands.
- **The same commands everywhere.** The setup and removal lines are
  `packaging/linux/verify-repo.sh`'s (LR-16), with `$BASE` set to the site.
  The website's new `test/linux-repos.spec.ts` checks that both languages
  show exactly those lines; comments in both point at each other and at
  README.
