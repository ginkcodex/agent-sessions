# LR-13 — Worker: signing and public key files

- **Status:** ⬜ Not started
- **Estimate:** 2.5 h
- **Depends on:** LR-02
- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

- Load `REPO_SIGNING_KEY` (armored Ed25519 OpenPGP private key: a v4 EdDSA key, LR-02) once per
  isolate.
- `InRelease` (clear-signed), `Release.gpg` (detached, armored) and
  `repomd.xml.asc` (detached, armored).
- Public files: `/apt/agent-sessions.gpg` (binary keyring),
  `/apt/agent-sessions.asc`, `/rpm/RPM-GPG-KEY-agent-sessions` (both public
  keys), and `/rpm/agent-sessions.repo` with `gpgcheck=1`,
  `repo_gpgcheck=1` and the key URL.

## Likely files

`web/src/server/repo/sign.ts`, `web/src/server/repo/keys.ts`, tests.

## Acceptance criteria and tests

- Signatures made in tests with a test key verify with `gpgv` and `sqv` in
  containers (the LR-02 commands).
- A missing or invalid key fails the rebuild with a clear error; the
  current generation stays served.
