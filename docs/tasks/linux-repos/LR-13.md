# LR-13 — Worker: signing and public key files

- **Status:** ✅ Done
- **Estimate:** 2.5 h
- **Depends on:** LR-02
- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

- Load `REPO_SIGNING_KEY` (armored Ed25519 OpenPGP private key: a v4 EdDSA key, LR-02) once per
  isolate.
- `InRelease` (clear-signed), `Release.gpg` (detached, armored) and
  `repomd.xml.asc` (detached, armored).
- Public files: `/apt/agent-sessions.gpg` (binary keyring),
  `/apt/agent-sessions.asc`, `/rpm/RPM-GPG-KEY-agent-sessions` (both public
  keys), and `/rpm/agent-sessions.repo` with `gpgcheck=1`,
  `repo_gpgcheck=1` and the key URL.

## Likely files

`web/worker/repo/sign.ts`, `web/worker/repo/keys.ts`, tests.

## Acceptance criteria and tests

- Signatures made in tests with a test key verify with `gpgv` and `sqv` in
  containers (the LR-02 commands).
- A missing or invalid key fails the rebuild with a clear error; the
  current generation stays served.

## Done

In `agent-sessions-web` (`feat/linux-repos`, commit 48e6ac3):

- `worker/repo/sign.ts`: a minimal OpenPGP v4 signer on WebCrypto Ed25519,
  so no OpenPGP library loads in the Worker.
  - `loadSigningKeys` reads every armored secret key in `REPO_SIGNING_KEY`
    (several blocks, or several keys in one block). Each primary key must be
    a v4 EdDSA key on Ed25519, exported without a passphrase, with a
    self-signature that allows signing; ECDH subkeys are allowed and left
    alone. Each key is checked by signing and verifying a probe. Expired keys
    are left out with a warning while one is left.
  - Errors are `SigningKeyError` with the reason: not set, no private key
    block, bad armor checksum, protected key, algorithm 27 or 1, every key
    expired, a key listed twice.
  - `signingKeys` caches the keys once per isolate for the same secret and
    drops a failed load, so the next rebuild reads the secret again.
  - Signatures are v4 with SHA-512, a creation time, the issuer fingerprint
    (hashed) and the issuer key ID. `clearSign` dash-escapes and signs the
    canonical text (CRLF, no trailing whitespace, no final line break);
    `detachedSignature` armors with a CRC24 line.
- `worker/repo/keys.ts`:
  - `signedFiles`: `InRelease` and `Release.gpg` signed by every key;
    `repomd.xml.asc` by the first key only, since dnf refuses a detached
    signature with two packets (below).
  - `keyFiles`: `apt/agent-sessions.gpg` (binary keyring),
    `apt/agent-sessions.asc` and `rpm/RPM-GPG-KEY-agent-sessions` (the
    repository key's block, then each block in `RPM_PUBLIC_KEYS`).
  - `RPM_PUBLIC_KEYS`: the RPM key's public block(s), committed. Empty until
    LR-15 makes the key.
  - `repoFile(origin)`: dnf's `.repo` with `gpgcheck=1`, `repo_gpgcheck=1`
    and the key URL. It is made per request from the origin, so a preview's
    file names the preview; LR-14 serves it.
- openpgp.js 6 is a dev dependency, used by the tests only.
