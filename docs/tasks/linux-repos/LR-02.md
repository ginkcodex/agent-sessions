# LR-02 — Spike: redirects and signatures

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** LR-01
- **Plan:** [linux-repos.md](../../plan/linux-repos.md)

## Scope

Check the assumptions the plan rests on, with a throwaway repository on the
LR-01 preview Worker and a test key:

- apt (Ubuntu 24.04, Debian 13, newest Ubuntu) and dnf (Fedora 40, newest
  Fedora) download a package through a 302 from our domain to a GitHub
  release asset, and on to GitHub's file host.
- An `InRelease` clear-signed by `openpgp` with an Ed25519 key verifies with
  `gpgv` and with `sqv` (newer Ubuntu), and `repomd.xml.asc` with dnf's
  `repo_gpgcheck=1`.
- nfpm signs an RPM with an Ed25519 key and Fedora 40's `rpm -K` accepts it.
  If not, the RPM key is RSA 4096 (the plan's default).

## Acceptance criteria and tests

- Each check recorded with the container, command and output.
- Any failed assumption updates [linux-repos.md](../../plan/linux-repos.md)
  before LR-08 or LR-11 starts.
