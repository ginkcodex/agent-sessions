## Scope and likely files

A process-wide recorder that keeps the most recent keyboard events in memory
and writes them as JSON Lines. It is shared by every window's App, and the
windows learn its state from an event. See the plan's "Recorder".

Likely files:

- a new `internal/keylog/` (the recorder and its tests);
- `internal/app/windows.go` (creates and shares the recorder, and broadcasts
  its state);
- a new `internal/app/keylog.go` (`KeyboardLogEnabled`,
  `RecordKeyboardEvents`);
- `frontend/src/lib/appBinding.ts` and `frontend/src/lib/api.ts`, to keep the
  binding contract.

## Acceptance criteria and tests

- While off, `Add` drops events.
- Turning recording on clears the buffer; turning it off keeps it.
- The buffer keeps the newest N events and counts the ones it drops.
- A saved log has a header line, then events ordered by time (stable for
  ties).
- Each state change reaches every started window as `keyboard-log:state`.
- `RecordKeyboardEvents` stamps page events with their own `t` and the window
  name. It ignores batches while off, and caps the batch size and the record
  size.
- Run the Go unit tests for `internal/keylog` and `internal/app`, and the
  binding contract test.
