# KD-02 — macOS native monitor and Help menu controls

- **Status:** 🟡 Partial (built and menu-tested; the monitor has not yet run in a live app, see KD-04)
- **Estimate:** 4 h
- **Depends on:** KD-01
- **Plan:** [keyboard-diagnostics.md](../../plan/keyboard-diagnostics.md)

## Scope and likely files

An `NSEvent` local monitor and notification observers that feed native
records to the recorder while it is on, plus a state snapshot taken when the
log is saved. Two Help menu items, Record Keyboard Events and Save Keyboard
Log, replace the toolkit's Learn More item. See the plan's "Native monitor"
and "Controls".

Likely files:

- new `cmd/agent-sessions/keylog_darwin.go`, `keylog_darwin.m` and
  `keylog_other.go`;
- `cmd/agent-sessions/about.go` (menu setup);
- `cmd/agent-sessions/run_gui.go` (hook at startup).

## Acceptance criteria and tests

- The monitor never changes or swallows an event. While recording is off it
  returns at once.
- Characters are read only for key events, never for flagsChanged events. No
  characters are recorded while Secure Event Input is on.
- Each record carries the CGEvent source PID, source state ID and user data,
  the first responder class, marked text, and the input sources.
- Activation, key window and input source changes are recorded as markers.
- The checkbox reflects the recorder's state. Saving writes a 0600 file under
  `~/Library/Logs/agent-sessions/` and shows its path. The Learn More item is
  gone.
- Builds on darwin and non-darwin desktop targets. Run `go vet` with the
  `desktop` tag for darwin, and cross-vet for Linux and Windows.

## Evidence

- What was done:
  - `keylog_darwin.m` and `.go`: a local monitor for keyDown, keyUp and
    flagsChanged that always returns the event and reads nothing while off.
    Each record has:
    - characters and code points, read for key events only and not while
      Secure Event Input is on;
    - the CGEvent PID, state ID, user data, key code, flags, timestamp and
      Unicode string;
    - the window, key window, first responder, marked text, input context
      source and client, and the TIS source and layout.
  - Markers for app active and inactive, window key and not key, context
    source changes, and system input source selection and enabling.
  - `keylog_snapshot` runs on the main thread and supplies the header state,
    including the OS version and the context's enabled sources.
  - `keylog_other.go` is a no-cgo stub.
  - `keylog_menu.go`: the Help menu gets Record Keyboard Events (checkbox)
    and Save Keyboard Log, and Learn More is removed. Saving takes the
    snapshot first, writes to `~/Library/Logs/agent-sessions/`, and shows the
    path without revealing it in Finder.
  - The hook is installed at `ApplicationStarted` in `run_gui.go`.
- Checks:
  - `go build -tags desktop ./cmd/agent-sessions` (darwin) builds with no
    compiler warnings (only the usual ld version warnings).
  - `go vet -tags desktop ./cmd/agent-sessions/` passes on darwin, and
    cross-vet passes on windows/amd64.
  - `go test -tags desktop ./cmd/agent-sessions/ -run 'HelpMenu|AppMenu'`
    passes: Learn More is gone, the checkbox is unchecked, the save item is
    there, and the About items are unchanged.
- Not checked:
  - The monitor and observers have not run in a live app.
  - A linux cgo desktop vet was not run: GTK pkg-config is not on this Mac,
    but the Linux path only uses the no-cgo stub.
