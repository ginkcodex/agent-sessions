# KD-03 — Page-side capture

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** KD-01
- **Plan:** [keyboard-diagnostics.md](../../plan/keyboard-diagnostics.md)

## Scope and likely files

While the recorder is on, capture-phase listeners record keyboard, input and
composition events in the page and send them to Go in batches. See the plan's
"Page capture".

Likely files:

- a new `frontend/src/lib/keyboardDiagnostics.ts` and its test;
- `frontend/src/main.ts`.

## Acceptance criteria and tests

- With recording off, no listeners are attached.
- Turning recording on attaches the listeners, and turning it off detaches
  them and drops anything not yet sent.
- Records hold the event fields from the plan and never a field's value.
  Inside password inputs, `key` and `data` are dropped.
- Batches are sent every 250 ms at most. A failed send drops its batch and
  does not throw.
- Test the record builder and the attach/flush/detach cycle with a fake
  runtime. Run `npm test`, `npm run check` and `npm run build`.
