## Scope

- Codex (`scan_rollout.go:661-668, 752-760`, `discover.go:44-49, 82-86`): one
  unreadable rollout or day directory fails the whole scan, so no new Codex
  sessions are indexed. The error also wraps a nil (`%!w(<nil>)`).
- Claude (`discover.go:44-47`, `scan.go:468-471`): a project directory that
  can't be read is skipped silently, its sessions are reported Removed, and
  they come back on the next scan.

Reviewer finding.

- Both carry the previous `SourceState` forward for a source that can't be
  read, and record a warning in the discovery status.
- Update `TestScan_UnreadableSourceRetainsState` to the new policy.

## Acceptance criteria and tests

- Tests per provider: an unreadable source keeps its sessions, other sources
  still index, and the warning appears.
