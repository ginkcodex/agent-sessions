## Scope

CI run 43690937665 (2026-11-15) finds no search results on Windows and macOS.
Search builds lexical paths under the supplied root while the regular-file opener
checks containment against its resolved root. Symlink roots (macOS temp paths)
and Windows path aliases can therefore reject every file.

Resolve the search root once before constructing file paths, keeping the shared
opener's containment and special-file protections unchanged.
