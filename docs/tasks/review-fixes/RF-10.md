# RF-10 — Openers honour Go's scheme check; keys never go over plain HTTP

- **Status:** ⬜ Not started
- **Estimate:** 1.5 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

- `api.ts:1785` ignores any error from Go's `OpenURL`, including "unsupported
  url scheme", and falls back to Wails `Browser.OpenURL` and
  `window.open`. Checked. Fall back only when the binding is missing, and
  let real failures reach the caller's toast.
- Translate base URLs (`internal/translate/translate.go:77`) and the repo
  ingest site (`notify-ingest.sh:20`) send a bearer key: refuse `http://`
  except for loopback.
- Middle-click on transcript links and OSC 8 terminal links go through
  `api.openURL` (an `auxclick` listener; xterm `linkHandler`).

## Acceptance criteria and tests

- Frontend test: a refused scheme throws and no fallback runs.
- Go test: an `http://` non-loopback translate URL is refused.
