# RF-11 — RPC replies match beyond 1,000,000 requests

- **Status:** ⬜ Not started
- **Estimate:** 1 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/rpc/client.go`: pending calls are keyed by `fmt.Sprintf("%d", id)`
(line 307), and replies by `fmt.Sprintf("%v", partial.ID)` with `ID any`
(lines 245, 267). A float64 of 1000000 prints as `1e+06`, so from then on no
reply finds its call and every call waits until its context ends. Pings
fail the same way. Checked.

- Decode `ID` as `json.Number` or `uint64`, and key both sides the same way.

## Acceptance criteria and tests

- A test whose client starts its ID counter near 1,000,000 and makes calls
  across the boundary.
