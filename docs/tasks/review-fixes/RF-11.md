# RF-11 — RPC replies match beyond 1,000,000 requests

- **Status:** ✅ Done
- **Estimate:** 1 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/rpc/client.go`: pending calls are keyed by `fmt.Sprintf("%d", id)`
(line 307), and replies by `fmt.Sprintf("%v", partial.ID)` with `ID any`
(lines 245, 267). A float64 of 1000000 prints as `1e+06`, so from then on no
reply finds its call and every call waits until its context ends. Pings
fail the same way. Checked.

- Decode `ID` as `json.Number` or `uint64`, and key both sides the same way.

## Acceptance criteria and tests

- A test whose client starts its ID counter near 1,000,000 and makes calls
  across the boundary.

## Evidence

Done on 2026-11-14.

- `internal/rpc/client.go`:
  - The read loop now decodes `id` as `json.RawMessage`.
  - `responseKey` turns any integer spelling (`1000000`, `1e6`,
    `1000000.0`) into the same decimal key `requestKey` gives a call. Other
    IDs keep their JSON text and match no call. An absent or `null` ID
    still marks a notification.
  - The liveness ping's reply is matched with the same keys.
- `internal/rpc/cancel.go`: `idKey` keys a decoded `float64` (and `int`,
  `int64`) ID in decimal form.
  - The server was already consistent with itself: the request ID and a
    `$/cancelRequest` ID both decode as `float64` and print alike. This
    change keeps both sides on one form.
- New `request_id_test.go`:
  - `TestCallsMatchRepliesPastOneMillionRequests`: a real server and client
    pair, with the counter set to 999,995. Ten pings across 1,000,000 must
    all get their reply within 2 s. A liveness ping at ID 2,000,000 must
    clear `pinging`.
  - `TestResponseKey`: covers absent, null, integer, exponent,
    `1000000.0`, a value above 2^53, fractional, and string IDs, plus
    `idKey` for each decoded type.
  - `TestCancelRegistryPastOneMillion`: a request decoded from `1000000`
    is cancelled by a cancel decoded from `1e6`.
- Against the old `client.go`, the first test fails at
  `call 4 (ID 1000000): context deadline exceeded`. With the fix it passes.
- `go test -race ./internal/rpc/`: pass. `go vet ./internal/rpc/`: clean.
  `gofmt`: clean.
