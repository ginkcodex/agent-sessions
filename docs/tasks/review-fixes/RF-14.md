# RF-14 — Coalesce watcher refreshes; close the engine safely

- **Status:** ⬜ Not started
- **Estimate:** 3.5 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/engine/engine.go:304-344, 436-445`: each change starts
`go e.refreshProvider` with no coalescing, and these goroutines are not in
`e.bg`. `Close` closes the DB without `Refresher.Retire()`, while
`LoadState`, `LoadCatalog`, `pendingFTSJobs` and `maintainFTS` read `d.db`
without `writeMu` (`index/db.go:248-258, 358`). Reviewer finding.

- Coalesce in `Refresher`: at most one running and one pending scan per
  provider.
- Track refreshes in `e.bg`; `Close` retires the refresher, waits, then
  closes the DB.
- Guard `d.db` reads, or make `Close` wait for readers.

## Acceptance criteria and tests

- `go test -race`: a test that fires changes while closing.
- A test: 50 changes during one slow scan run at most two scans.
