# RF-35 — Accept cancelled ACP prompt replies during shutdown

- **Status:** ✅ Done
- **Estimate:** 1 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

CI run 43694948130 fails `TestCloseAnswersPendingPermission` on macOS.
Close intentionally answers pending permissions as Cancelled before closing the
connection. The agent may return a valid `cancelled` stop reason before EOF;
the test currently mistakes any nil RPC error for a successful turn.

Check the stop reason as well as the transport error; retain the bounded Close
assertion and require the child process to exit. Do not change production shutdown.

- A valid `cancelled` reply is accepted, but a normal successful turn is not.
- Close still completes without waiting for the blocked permission callback.
- Repeated focused tests and the ACP race suite pass.
- Native macOS validation is recorded separately from local tests.
