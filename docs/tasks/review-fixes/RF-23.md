# RF-23 — `config.toml` values round-trip; long lines are not lost

- **Status:** ✅ Done
- **Estimate:** 2 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/configfile/configfile.go:116-150`: `Value` returns the raw quoted
text without unescaping. `SetValue` writes `strconv.Quote`, which can produce
`\x` escapes that are invalid TOML. The translate API key (`app/translate.go:70`)
gains backslashes on every save. `Scanner.Err()` isn't checked, so a line
over 64 KiB truncates the rest of the file on rewrite. Reviewer finding.

## Acceptance criteria and tests

- Round-trip tests for values with `\`, `"`, control characters and
  non-ASCII.
- A test with a line over 64 KiB: the rewrite keeps every line, or fails
  without writing.

## Evidence

- Confirmed the quoted-value parser returned raw text and stopped at an escaped
  quote, while the two unchecked scanners could truncate reads/rewrites at
  64 KiB. All `Value`/`SetValue` callers were checked: translate settings,
  terminal selection/open mode and update settings.
- Quoted values now use the existing BurntSushi TOML decoder. New
  `configfile.Quote` uses that dependency's encoder rather than Go string
  quoting; every string-writing caller uses it. Bare values (including update
  booleans) retain their existing behavior. String splitting replaces both
  bounded scanners, retaining long lines and unrelated content on rewrite.
- Added repeated string round trips for backslashes, escaped quotes, control
  characters, Unicode and literal escape text, quoted/commented value parsing,
  malformed string handling, and an on-disk update containing 128 KiB comment
  and value lines with subsequent tables/blank lines preserved exactly.
- Added an app regression: a manually configured escaped legacy API key stays
  byte-for-byte unchanged through three settings saves; the shared manage
  reader still accepts the resulting TOML. New API-key validation is unchanged
  (new keys containing quotes/backslashes/control characters are still refused).
- Passed `go test -count=1 ./internal/configfile ./internal/remote
  ./internal/launch ./internal/app ./internal/manage ./internal/translate` and
  the same package list with `go test -race -count=1`.
- Limitations: the existing line-oriented editor is not a full TOML document
  editor (multiline values/complex table syntax were not expanded in scope).
  Already-corrupted saved secrets cannot be reconstructed automatically; no
  real provider request or desktop UI test was run.
