# RF-23 — `config.toml` values round-trip; long lines are not lost

- **Status:** ⬜ Not started
- **Estimate:** 2 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/configfile/configfile.go:116-150`: `Value` returns the raw quoted
text without unescaping. `SetValue` writes `strconv.Quote`, which can produce
`\x` escapes that are invalid TOML. The translate API key (`app/translate.go:70`)
gains backslashes on every save. `Scanner.Err()` isn't checked, so a line
over 64 KiB truncates the rest of the file on rewrite. Reviewer finding.

## Acceptance criteria and tests

- Round-trip tests for values with `\`, `"`, control characters and
  non-ASCII.
- A test with a line over 64 KiB: the rewrite keeps every line, or fails
  without writing.
