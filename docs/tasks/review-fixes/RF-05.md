# RF-05 — Terminal pastes cannot end bracketed paste early

- **Status:** ⬜ Not started
- **Estimate:** 2 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`terminalClipboard.ts` accepts any OSC 52 write from terminal output. xterm's
`paste()` passes ESC through, so text containing `\e[201~` can end
bracketed paste early and run what follows. `runCommand.ts` already strips
controls for the Run button. Checked.

- Before paste (the menu item and Ctrl/Cmd+V), strip C0 and C1 controls
  except tab and newline, as `runCommand.ts` does.
- Cap OSC 52 payloads (for example 1 MiB) and drop control characters in
  them.
- Strip zero-width and bidi characters from Run-button commands too
  (U+200B–200F, U+202A–202E, U+2066–2069).

## Likely files

`frontend/src/lib/terminalClipboard.ts`, `runCommand.ts`,
`components/terminal/TerminalView.svelte`, `frontend/test/terminal*.test.mjs`.

- A test for oversize OSC 52 payloads and for the bidi stripping.
