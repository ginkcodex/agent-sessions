# RF-19 — Reading a FIFO or special file never hangs

- **Status:** ✅ Done
- **Estimate:** 1.5 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/files/files.go:615` (`Read`), `blame.go:39`, `git_diff.go:248` and
`external.go:36` call `os.Open` before checking for a regular file. Opening
a FIFO with no writer blocks forever. `walkPaths` lists FIFOs as files.
`search.go:267` already does it right. Checked for `Read`.

- Lstat (or open with `O_NONBLOCK`) and refuse non-regular files before
  opening them.
- Show special files in the tree as non-openable, or leave them out.

## Acceptance criteria and tests

- Unix tests: `Read`, blame and the working-copy diff on a FIFO return an
  error at once.

## Evidence

- Added a shared rooted regular-file opener: Unix `O_NONBLOCK` prevents a
  regular-to-FIFO replacement from blocking; `O_NOFOLLOW`, descriptor `Stat`,
  identity comparison and `os.Root` preserve race-safe containment. Existing
  selected symlinks still resolve before opening; directory ZIPs still refuse links.
- Applied it to Read, blame, working-copy diff, external source reads, search
  and download reads. ListDirectory now uses a rooted nonblocking open too.
  Walked trees and expanded directories omit FIFOs, sockets and other special files.
- Added Unix timeout regressions for FIFO, symlink-to-FIFO and socket reads
  through all these routes, including public ReadGitDiff; concurrent regular,
  FIFO and outside-symlink swaps verify no hangs or outside contents.
- Passed `go test ./internal/files` and `go test -race ./internal/files`.
- Passed final targeted race run:
  `go test -race ./internal/files -run 'TestSpecialFile|TestRegularOpen|TestReadExternal|TestDownload' -count=1`.
- Windows amd64 test binary cross-compilation passed for `internal/files`
  (`GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go test -c`, output under `/tmp`).
- Not checked: Windows runtime or real device-driver I/O. Unix nonblocking
  flags address FIFO-open races; they do not guarantee arbitrary driver latency.
