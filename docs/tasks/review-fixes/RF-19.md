# RF-19 — Reading a FIFO or special file never hangs

- **Status:** ⬜ Not started
- **Estimate:** 1.5 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/files/files.go:615` (`Read`), `blame.go:39`, `git_diff.go:248` and
`external.go:36` call `os.Open` before checking for a regular file. Opening
a FIFO with no writer blocks forever. `walkPaths` lists FIFOs as files.
`search.go:267` already does it right. Checked for `Read`.

- Lstat (or open with `O_NONBLOCK`) and refuse non-regular files before
  opening them.
- Show special files in the tree as non-openable, or leave them out.

## Acceptance criteria and tests

- Unix tests: `Read`, blame and the working-copy diff on a FIFO return an
  error at once.
