# RF-17 — Chat start can be cancelled and times out

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** RF-16
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/app/chat.go:194` passes `a.appCtx()`, which has no deadline, into
`initialize` and `session/new|load|resume`. Until the start returns the
frontend has no `chatId`, so it can't close the chat, and `ChatOpener.run`
(`chatOpen.svelte.ts:232`) refuses every other open while one is starting.
Checked: the context has no deadline.

- A start timeout (for example 60 s, configurable) and a `ChatStartCancel`
  keyed by a client-chosen start token.
- LiveTail shows Cancel while a chat starts.

## Acceptance criteria and tests

- `acptest`: an agent that never answers `initialize` fails the start at the
  timeout and is killed. Cancel stops the start at once.
- Frontend test: a failed or cancelled start frees the opener.
