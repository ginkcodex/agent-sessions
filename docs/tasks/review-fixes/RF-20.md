# RF-20 — A language server restarts after a crash

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/codediagnostics/lsp_session.go:461`: `attach` on a failed session
returns the old error. `SessionManager.Retry` (`:641`) has no production
caller, and the frontend `canRetry` (`codeDiagnostics.svelte.ts:208`) is
limited to `savedProject`. After an OOM kill, or a reply over 8 MiB, live
diagnostics stay dead until the app restarts. The comment at `:639`
contradicts the code. Reviewer finding.

- Restart automatically with backoff and a cap, then offer Retry in the UI.
- Count an attempt only after `Preflight` passes.

## Acceptance criteria and tests

- A test with a fake server that crashes once: the session recovers without
  an app restart.
