# RF-27 — Run the fish panel startup test in a terminal

- **Status:** ⬜ Not started
- **Estimate:** 2 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/launch/panel_agent_test.go` `TestRemotePanelAgentStartup` runs
each shell with `CombinedOutput`, so there is no terminal. Without one,
fish (3.7.1 in the `make test-ssh` image) reads EOF from stdin and exits 0
without firing `fish_prompt`, so the agent never runs. All three fish cases
fail on any machine with fish installed. This machine and CI don't have it,
so the cases always skipped. Found during RF-26. With `docker run -t`, fish
does fire `fish_prompt`, so real panel tabs, which have a pty, aren't
affected.

- Run the shells under a pty (`github.com/aymanbagabas/go-pty` is already a
  dependency) and keep the result file and exit status checks.
- Consider installing zsh, fish and tcsh in the CI test job, so these cases
  run somewhere.

## Acceptance criteria and tests

- With fish installed, the fish cases pass; bash, zsh and tcsh still pass.
