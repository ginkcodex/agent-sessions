# RF-24 — golangci-lint and govulncheck in CI

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

The Definition of Done requires `golangci-lint`, but CI doesn't run it. A
local run reports 156 issues: errcheck 50, unused 35 (many false positives
from linting on Linux only), unparam 21, staticcheck 21, errorlint 10,
nilerr 6. Neither `govulncheck` nor `npm audit` runs in CI. Reviewer finding.

- Fix the 6 `nilerr` hits (`internal/manage/restore_codex.go:310,322,342`,
  `claude_leftovers.go:47,216`, `files/git_submodule.go:16`).
- Run `golangci-lint` in CI with `--new-from-rev` (or a baseline) so only new
  issues fail. Run it per GOOS to drop the `unused` false positives.
- `govulncheck ./...` and `npm audit --omit=dev` in CI.
- Optional: run `go test -race` on macOS too.

## Acceptance criteria and tests

- CI fails on a new lint issue and on a known vulnerability; it passes on
  `develop`.
