# RF-03 — Pin GitHub Actions to commit SHAs

- **Status:** ⬜ Not started
- **Estimate:** 1.5 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

Every `uses:` in `.github/workflows/*.yml` and `.github/actions/**` points at
a moving tag (`actions/checkout@v7` and others), including in the jobs that
hold secrets.

- Pin each one to a full commit SHA, with the tag in a comment.
- Add `.github/dependabot.yml` for `github-actions` so the pins get update
  PRs.

## Acceptance criteria and tests

- `git grep -nE 'uses: [^ ]+@v[0-9]' .github` finds nothing.
- CI and a dispatch on `main` pass.
