# RF-22 — Port forwarding on OpenSSH before 8.7

- **Status:** ⬜ Not started
- **Estimate:** 2 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

`internal/remote/forward.go:53` passes `-o ForkAfterAuthentication=no`, which
OpenSSH before 8.7 rejects ("Bad configuration option"). That includes
Windows 10's built-in 8.1, Ubuntu 20.04 (8.2) and RHEL 8 (8.0). Reviewer
finding, not tested.

- Omit the option, since it is the default, or add it only when `ssh -V`
  reports 8.7 or later.

## Acceptance criteria and tests

- A test of the argument list per `ssh -V` version.
- One forward through an OpenSSH 8.x client, if one is at hand.
