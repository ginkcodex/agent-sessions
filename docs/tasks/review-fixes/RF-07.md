# RF-07 — Path-taking App methods refuse credential files

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** None
- **Plan:** [review-fixes.md](../../plan/review-fixes.md)

## Scope

All public `App` methods can be called from the webview. `ChatAttachFiles`,
`TerminalDropFiles` and `OpenBundlePath` read any local path, and
`TerminalDropFiles` can upload up to 100 MB to a remote host.
`SetManageEnabled` and `SetAllowPermanentDelete` switch on deletes. SPEC §9
forbids reading `.credentials.json` and `auth.json`. The markdown sanitizer
held up in the review, so this is defence in depth. Reviewer finding.

- One shared check for webview-supplied paths: refuse agent credential files
  (`~/.claude/.credentials.json`, `~/.codex/auth.json`, OpenCode's
  `auth.json`) and `~/.ssh/`, with an error that says why.
- Decide whether the opt-in switches need a native confirmation, and record
  the decision in the plan.

## Likely files

`internal/app/chat_attach.go`, `panel.go`, `bundle*.go`, `manage*.go`,
`internal/pathutil`.

## Acceptance criteria and tests

- Tests: each method refuses the denylisted paths (including through a
  symlink) and still accepts a normal file.
