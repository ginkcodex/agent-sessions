## Evidence

- Reproduced both existing fish cwd-prompt cases failing without terminal
  markers in the shell-enabled `agent-sessions-sshd:test` image (fish 3.7.1).

  exact cwd-marker ordering, failed-cd behavior, scalar/array hooks, profile
  immutability and integration-wrapper cleanup assertions. Isolated fish's
  config directory with `XDG_CONFIG_HOME` like the startup test.

  appearances overcounts invocations under a real PTY. The fish fixture now

  invocations and checks the emitted cwd markers. fish-owned temp files do not
  count as leaked app integration wrappers.

  `go test -race -count=1 ./internal/launch` on the host (bash cases execute;
  zsh/fish/tcsh unavailable locally).

  /tmp/rf29-launch.test ./internal/launch`, then passed the full suite using
  `docker run --rm -v /tmp/rf29-launch.test:/panel.test:ro --entrypoint
  /panel.test agent-sessions-sshd:test -test.timeout=90s`. Both fish cwd-prompt
  cases, both zsh cwd-prompt cases, all fish/zsh startup cases and both tcsh
  startup cases executed successfully. Bash and installed-locale discovery
  skip in this Alpine image because those tools are absent.
- Passed the container startup/cwd matrix ten consecutive times with
  `-test.run 'TestPanelShellPromptCwd|TestRemotePanelAgentStartup' -test.count=10`.
