# FT-01 — Translate an entire file from preview

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** —
- **Plan:** [file-translate.md](../../plan/file-translate.md)

## Scope

Add whole-file translation to the rendered Markdown preview context menu without
requiring a text selection. Reuse whole-content translation and message-style
in-place display/toggle/retry semantics, leaving the selected-text flow unchanged.
Translate complete loaded source text read-only; source/diff/image views stay unchanged.

## Likely files

- File preview and shared translation/context-menu components in `frontend/src/lib/`
- Preview/translation regression tests in `frontend/test/`

## Acceptance criteria

- No-selection right-click offers `Translate entire file` for complete non-empty
  rendered Markdown previews; requests use all source content.
- Selection translation keeps its existing behavior and priority.
- Empty, binary, too-large, loading/error and editing states do not offer it.
- Loading, settings guidance, original/translation toggles and Retry follow the
  existing message translation UI semantics. Copy/print follow displayed preview.
- No original file contents are modified and no new backend endpoint is needed.

## Tests

Add component regression coverage for text/Markdown payloads, eligibility,
selection priority, translation pending/result/error states. Run focused tests,
full frontend tests, `npm run check` and `npm run build`. Record any desktop or
live-provider validation not performed.
