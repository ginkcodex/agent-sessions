# FS-07 — Project docs preview size

- **Status:** ⬜ Not started
- **Estimate:** 1 h
- **Depends on:** FS-01, FS-03
- **Plan:** [font-settings.md](../../plan/font-settings.md)

## Scope

- `FileViewer.svelte`: the Markdown preview sets `--markdown-font-size` to
  the presentation size when presenting, else
  `var(--docs-font-size, 14.5px)`. Since FS-01 sizes every role from that
  body, headings, tables, code and tags follow with their ratios.
- Find highlights and the saved preview scroll position repaint on change.
- The import and handoff dialogs keep their 13 px body.

## Likely files

`components/common/go-to-file/FileViewer.svelte`,
`frontend/test/go-to-file.test.mjs`.

## Acceptance criteria

- Default: the preview body is 14.5 px as today.
- A set size applies to the preview only, and the heading-to-body and
  code-to-body ratios are the same at 11, 14.5 and 28 px.

## Tests

SSR check of the preview's style attribute with and without the setting and
in presentation mode.
