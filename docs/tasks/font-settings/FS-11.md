# FS-11 — Built-in terminal text size

- **Status:** ✅ Done
- **Estimate:** 2 h
- **Depends on:** FS-03, FS-04
- **Plan:** [font-settings.md](../../plan/font-settings.md)

Requested after FS-09: let the user choose the built-in terminal's font
size, as they can choose its font.

## Scope

- `appearance.ts`: a `terminal` size kind, 9–28 px, default 13 px. It is
  not a CSS property: xterm.js takes the size as an option.
- `preferences.svelte.ts`: `terminalFontSize` in
  `agent-sessions:terminal-font-size`, loaded, validated and reset like the
  other sizes.
- `TerminalView.svelte`:
  - a new terminal opens at the chosen size, with the font loaded at that
    size first;
  - a change sets `fontSize` on every open terminal and refits it, so the
    program gets the new columns and rows.
- Settings → Terminal: a "Built-in terminal text size" stepper below the
  terminal font, and the font sample shown at that size.

## Likely files

`frontend/src/lib/appearance.ts`, `frontend/src/lib/stores/preferences.svelte.ts`,
`frontend/src/lib/components/terminal/TerminalView.svelte`,
`frontend/src/lib/components/common/TerminalFontSetting.svelte`,
`frontend/test/appearance.test.mjs`, `frontend/test/terminal-font*.test.mjs`.

## Acceptance criteria

- Default: terminals stay at 13 px, and nothing is stored.
- A size outside 9–28 px, or garbage in storage, is the default.
- Changing the size resizes open terminals at once. Their columns and rows
  change to fit the panel, and the program is told.
- The setting is kept after a restart.
- `npm test`, `npm run check` (0 errors) and `npm run build` pass.

## Outcome

- `appearance.ts`: a `terminal` size kind, 9–28 px, default 13 px. It adds
  nothing to `appearanceVars`: there is no CSS property.
- `preferences.svelte.ts`: `terminalFontSize`, stored in
  `agent-sessions:terminal-font-size`, using the same load, set and reset
  code as the other sizes.
- `TerminalView.svelte`:
  - A new terminal loads its font at the chosen size and opens at that size.
  - The font effect now follows the size too. On a change it sets both
    options and calls `resize()`. That refits the terminal and sends the new
    columns and rows to a running program.
  - Each open terminal, including split panes, runs its own effect.
- `TerminalFontSetting.svelte`: a "Built-in terminal text size" stepper
  below the font picker (13px default, Reset), and the font sample uses the
  size.
- Tests: `test/helpers.mjs` has a shared `loadTerminalFontSetting()` with the
  real stepper. The Settings dialog test and the terminal font test use it.
