# FS-01 — Type scale: tokens, message text and docs preview

- **Status:** ⬜ Not started
- **Estimate:** 4 h
- **Depends on:** —
- **Plan:** [font-settings.md](../../plan/font-settings.md)

Ratios first: no setting is added here. Sizes move only as the plan's type
scale table says (at most 0.5 px; inline code to 0.85em).

## Scope

- `frontend/src/style.css`: the eight ratio tokens from the plan's type
  scale table (`--type-h1` 1.43, `--type-h2` 1.25, `--type-h3` 1.08,
  `--type-body` 1, `--type-code` 0.92, `--type-small` 0.83, `--type-label`
  0.79, `--type-tag` 0.75) and `--type-inline-code` 0.85, as unitless custom
  properties on `:root`, with a comment that they are ratios of the body size
  and that no other text sizes are allowed in the docs preview or session
  content.
- `parts/TextPart.svelte`: body `var(--session-font-size, 14.5px)`; headings,
  tables, code blocks (`--type-code`), code language tag and
  Copy/Mermaid buttons (`--type-tag`) as
  `calc(var(--session-font-size, 14.5px) * var(--type-…))`; inline code
  `calc(var(--type-inline-code) * 1em)`.
- `MarkdownDoc.svelte`: the same roles with
  `var(--markdown-font-size, 13px)` as the body. Tables and code blocks move
  from 0.923em to `--type-code`; the fixed 10.88 px language tag and
  Copy/Mermaid buttons become `--type-tag`; inline code 0.85em.
- The global `.code-block-container` rules in `style.css` stay as they are
  for hover cards; the transcript and docs keep their own scoped rules.
- A test helper that reads the tokens and maps old px values to the token the
  plan assigns, used by this task's and FS-02's tests.

## Likely files

`frontend/src/style.css`, `components/transcript/parts/TextPart.svelte`,
`components/common/MarkdownDoc.svelte`, `frontend/test/type-scale.test.mjs`
(new), `frontend/test/markdown.test.mjs`.

## Acceptance criteria

- Every `font-size` in `TextPart` and `MarkdownDoc` is body × one of the
  eight tokens, or `em` × `--type-inline-code`.
- At a 14.5 px body: h1 20.7, h2 18.1, h3 15.7, table/code 13.3, tag 10.9 px,
  inline code 0.85em.
- A table or code block nested in a list or quote has the same size as at
  the top level.

## Tests

`type-scale.test.mjs`: parses the token block from `style.css` and checks it
against the plan's table (exactly these nine tokens); static check of the two
components' rules and their default sizes.
