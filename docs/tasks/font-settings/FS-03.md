## Scope

- `PreferencesStore` (`frontend/src/lib/stores/preferences.svelte.ts`):
  `editorFont`, `editorFontSize`, `docsFontSize`, `sessionFontSize`, with
  setters, `localStorage` keys and ranges as in the plan's Preferences table.
  `null` is the default (no override); `''` is the default editor font.
  Invalid, out-of-range or unreadable values fall back to the default;
  values are rounded to 0.5 px. Storage errors keep the choice for the run,
  as the existing setters do.
- `frontend/src/lib/appearance.ts`: pure functions
  - `appearanceVars(prefs)` → the root custom properties
    (`--editor-font-family`, `--editor-font-size`, `--docs-font-size`), each
    omitted when its preference is the default;
  - `sessionFontVar(size)` → the `--session-font-size` value, or none for the
    default;
  - the size limits, defaults and step helpers (`stepSize(value, default,
    ±1, range)`: whole-pixel steps, a fractional default steps to the next
    whole number).
- Generalize `terminalFontFamily` (`terminalFont.ts`) to a monospace-family
  builder used by both fonts; keep the terminal's behavior and name or alias
  it so callers do not change.
- `App.svelte`: one `$effect` that sets and removes the root properties.

## Acceptance criteria

- Defaults produce no custom properties at all.
- A stored valid value survives `init()`; garbage (`"abc"`, `-3`, `1e9`,
  control characters in the font name) is ignored.
- Step helpers: 14.5 → 15 / 14; limits are not crossed; 0.5 px rounding.
