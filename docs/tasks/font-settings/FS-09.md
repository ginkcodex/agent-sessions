- **Status:** 🟡 Partial: the automated gate and the browser checks passed; the manual pass in the Linux (WebKitGTK) and Windows (WebView2) desktop apps has not been run
- **Estimate:** 3 h

## Scope

- Full frontend run: `npm test`, `npm run check` (0 errors), `npm run build`;
  `git diff --check`.
- Manual check in the desktop app on Linux (WebKitGTK) and in a Windows test
  build (WebView2), following CLAUDE.md for the Windows folder:
  1. Defaults: editor, viewer and diff look as before; docs preview and a
     long session differ only by the planned size merge and the larger inline
     code (compare with a screenshot of the previous build).
  2. Ratios: at the smallest and largest docs and session sizes, headings,
     tables, code blocks, inline code, tool and patch labels and tags keep
     their proportions to the body text.
  3. Editor: choose an installed font (e.g. a Nerd Font) and 20 px; open a
     file, switch to editing and back — the text does not move; click, select
     and cursor positions are right; line numbers fit; overview ruler marks
     line up; find highlights land on the matches.
  4. Change the editor size with a file open in the editor.
  5. Remove the chosen font (or set a missing name): fallback, "(unavailable)".
  6. Docs preview at 11 and 28 px: find and scroll position.
  7. Session text at 11 and 24 px: no clipped text in tool headers, badges,
     patches, reasoning and compaction parts; a following transcript stays at
     the bottom; a scrolled transcript keeps its place; selection menu and
     file links work.
  8. Presentation mode overrides and returns to the saved sizes.
  9. Restart: all settings kept.
  10. Terminal size (added with FS-11): change it with a shell and a TUI open,
      including split panes; the program redraws at the new columns and rows.
