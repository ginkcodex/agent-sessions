# FS-05 — Settings → Appearance section

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** FS-03, FS-04
- **Plan:** [font-settings.md](../../plan/font-settings.md)

## Scope

- Add `'appearance'` to `SettingsSection` (`stores/manage.svelte.ts`) and an
  "Appearance" entry after General in `ManageSettingsDialog.svelte`.
- Groups:
  - **Editor:** font picker (FS-04) bound to `preferences.editorFont`, and a
    size stepper bound to `editorFontSize`; sample of code in the chosen font
    and size.
  - **Project docs preview:** "Text size" stepper.
  - **Session content:** "Text size" stepper.
  The docs and session samples show a heading, body text, inline code and a
  two-line code block sized with the same `--type-*` ratios, so the user sees
  them scale together.
- A shared stepper component (− value +, Reset), showing the body size in px
  and "(default)" when unchanged; buttons disabled at the limits; Reset
  hidden or disabled at the default. Keyboard and screen-reader labels as for
  the presentation-mode buttons (`aria-live` on the value).
- Hint text: sizes are the body text; headings, code and labels scale with
  it. Settings apply to this computer only, at once, to open files and
  sessions.

- `SettingsSection` has `'appearance'`; Settings lists **Appearance** after
  General and renders `AppearanceSettings.svelte` (new): an intro hint, then
  **Editor** (font size stepper, then the shared font picker as "Font" with a
  code sample in the chosen font at `var(--editor-font-size, 0.78rem)`),
  **Project docs preview** and **Session content** (a "Text size" stepper
  and a sample each).
- `SizeStepper.svelte` (new): − value + and Reset in a labelled group; the
  value (`aria-live`) shows the body size, "(default)" when unchanged (the
  editor default shows as 14px); − and + are disabled at the limits, Reset at
  the default. Steps use `stepSize`; Reset sets null.
- `TypeSample.svelte` (new): heading (`--type-h2`), body text, inline code
  (0.85em), a two-line code block (`--type-code`) and a label
  (`--type-label`), all from one `--sample-body`. The docs sample uses
  `var(--docs-font-size, 14.5px)`, the session sample the session size.
- `MonoFontSetting` takes an optional `sampleSize`.
- `test/helpers.mjs`: `loadAppearanceSettings()` for the section with its
  real stepper, sample and picker.
