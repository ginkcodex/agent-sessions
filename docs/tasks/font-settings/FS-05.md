# FS-05 — Settings → Appearance section

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** FS-03, FS-04
- **Plan:** [font-settings.md](../../plan/font-settings.md)

## Scope

- Add `'appearance'` to `SettingsSection` (`stores/manage.svelte.ts`) and an
  "Appearance" entry after General in `ManageSettingsDialog.svelte`.
- Groups:
  - **Editor:** font picker (FS-04) bound to `preferences.editorFont`, and a
    size stepper bound to `editorFontSize`; sample of code in the chosen font
    and size.
  - **Project docs preview:** "Text size" stepper.
  - **Session content:** "Text size" stepper.
  The docs and session samples show a heading, body text, inline code and a
  two-line code block sized with the same `--type-*` ratios, so the user sees
  them scale together.
- A shared stepper component (− value +, Reset), showing the body size in px
  and "(default)" when unchanged; buttons disabled at the limits; Reset
  hidden or disabled at the default. Keyboard and screen-reader labels as for
  the presentation-mode buttons (`aria-live` on the value).
- Hint text: sizes are the body text; headings, code and labels scale with
  it. Settings apply to this computer only, at once, to open files and
  sessions.

## Likely files

`stores/manage.svelte.ts`, `components/common/ManageSettingsDialog.svelte`,

- The section is listed and opens with `manage.openSettings('appearance')`.
- Steppers call the store setters; limits and Reset work; samples use the
  same custom properties and tokens as the real views.
