# FS-02 — Type scale: other session parts, clipping audit, scan test

- **Status:** ⬜ Not started
- **Estimate:** 4 h
- **Depends on:** FS-01
- **Plan:** [font-settings.md](../../plan/font-settings.md)

## Scope

- Convert every text size in the rest of the session content to
  `calc(var(--session-font-size, 14.5px) * var(--type-…))`, using the token
  the plan's table assigns to today's px value:
  - 13.7 px reasoning text, 12.8 px tool name → `--type-code`;
  - 12.48 px and 12 px → `--type-small`;
  - 11.52 px and 11.2 px → `--type-label`;
  - 10.88 px and 10.4 px → `--type-tag`.
  Files: `MessageBubble.svelte`, `parts/ToolPart.svelte`, `PatchPart.svelte`,
  `ReasoningPart.svelte`, `CompactionPart.svelte`, `NoticePart.svelte`,
  `ImagePart.svelte`, `SubagentLink.svelte`, and any other component rendered
  inside `.messages-scroll-area` found by the scan. No component keeps its own
  size.
- Leave unscaled, and list in the scan test's exceptions with a reason, only
  non-text items: icons and icon glyphs (role icon, the 14 px reset glyph),
  images, and the view controls in the scroll area (Load earlier,
  end-of-transcript marker, empty notice) that follow the app size.
- Audit fixed `height`/`line-height` in px on text containers (badges, tool
  headers, pills, one-line summaries) and switch them to unitless line
  heights or `min-height`, so larger text is not clipped.
- Scan test: reads the `<style>` blocks of the session-content components
  and `MarkdownDoc`, and fails on a `font-size` that is not body × one of the
  eight tokens, `em` × `--type-inline-code`, or a listed exception.

## Likely files

`components/transcript/MessageBubble.svelte`,

## Acceptance criteria

- The scan test passes; its exceptions are non-text items only, each with a
  reason.
- At a 14.5 px body each converted size is its token's size, within 0.5 px of
  today's.
- No fixed-px line height or height remains on a text container.

## Tests

The scan test and the mapping test (old px → token) for every converted
rule; existing transcript tests pass.
