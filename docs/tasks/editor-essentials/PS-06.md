# PS-06 — Keep search result actions clear of result information

- **Status:** ✅ Done
- **Estimate:** 1 h
- **Depends on:** PS-03, PS-05
- **Plan:** [editor-essentials.md](../../plan/editor-essentials.md)

## Scope

Give file and match dismiss/replace buttons their own space instead of overlaying
match counts or line numbers. Reserve that space while actions are hidden to
avoid hover shifts; keep action-free references compact. Preserve dismissal,
replacement, collapse and navigation behavior.

## Likely files

- `frontend/src/lib/components/common/go-to-file/SearchPane.svelte`
- `frontend/test/content-search.test.mjs`

## Acceptance criteria

- Counts and line numbers remain visible when dismiss or replace actions appear.
- Hidden actions retain their layout space; hover, active and keyboard-focus
  reveal states remain supported.
- File names/directories and previews truncate within the remaining width.
- Reference results reserve no empty action space.

## Tests

Add search/replace/reference render assertions and a regression guard for the
in-flow, non-shrinking action layout. Run frontend tests, svelte-check and build.
Record native visual checks only if actually run.
