## Scope

`EditorPlace` (range optional, `preview`) replaces `SourceLocation` in
`SourceHistory`; equality covers `preview` and a missing range; `remap`
for renames. `FilesStore` keeps one `SourceHistory` per directory (at most
20, least recently shown dropped), exposes the current one with a reactive
version, records the place read by `setPlaceReader` when `openFile` or
`selectTab` changes the shown working tab, and offers `withoutHistory` for
opens that record themselves. Rename remaps, delete forgets, `reset()`
drops all; `close()` and switching projects keep them.

## Acceptance criteria and tests

- Switching between working tabs records the place left; the same tab, a
  closed tab's neighbour, a Git review or a history tab does not.
- A throwing or missing place reader never stops a file from opening.
- `withoutHistory` suppresses recording, also when its callback throws.
- History survives `close()` and `show()` of another directory; each
  directory has its own; `reset()` clears; the 21st directory drops the
  least recently shown.
- Rename remaps places under the path (prefix boundary kept); delete drops
  them.
