# WS-03 — Star new workspaces from the session-list panel

- **Status:** ✅ Done
- **Estimate:** 1 h
- **Depends on:** WS-01
- **Plan:** [workspace-stars.md](../../plan/workspace-stars.md)

## Scope

Add a star toggle to the new-workspace information panel in the second column. A newly opened workspace hidden by the starred-only sidebar can be starred directly without clearing the filter.

## Likely files

- `frontend/src/lib/components/sessionlist/WorkspaceStart.svelte`
- `frontend/test/workspace-stars.test.mjs`

## Acceptance criteria

- The panel shows an accessible Star workspace / Unstar workspace toggle that reflects the shared persisted preference.
- Starring makes the workspace eligible for the starred-only sidebar immediately, without changing filters or navigating.
- Stale/locked links disable the toggle; existing new-session, shell and file controls remain unchanged.

## Tests

- Actual client panel DOM tests for pressed state, starring/unstarring with starred-only active, persistence, host isolation and disabled state.
- Workspace/tree regressions, full frontend tests, type checks and production build. Record actual results and native testing gaps.
