# WS-01 — Workspace stars and starred-only filter

- **Status:** ✅ Done
- **Estimate:** 4 h
- **Depends on:** —
- **Plan:** [workspace-stars.md](../../plan/workspace-stars.md)

## Scope

Implement persistent, host-scoped workspace stars and an accessible starred-only button next to the directory filter. Compose with existing filters in every grouping mode, preserve navigation and show a useful empty state.

## Likely files

- `frontend/src/lib/workspaceStars.ts`, `frontend/src/lib/stores/workspaceStars.svelte.ts`
- `frontend/src/lib/components/sidebar/{GroupNodeItem,GroupTree,PathFilter}.svelte`
- `frontend/src/lib/icons.ts`
- `frontend/test/workspace-stars.test.mjs` and existing tree/discovery fixtures

## Acceptance criteria

- Workspace star buttons reflect saved state and do not navigate on click/keyboard activation.
- Stars persist per data host and canonical path; invalid or inaccessible storage is tolerated.
- Header star button toggles starred-only filtering alongside directory filtering.
- Directory-first, agent-first and flat trees filter without mutating the source or removing matching descendants; empty state can clear the star filter.
- Existing selection/collapse state and the open transcript are unchanged by star actions.

## Tests

- Unit/store tests for persistence, identity, host switching, blocked links, malformed storage and filter semantics.
- Component tests for controls, accessibility and filtered/empty rendering; browser DOM event tests where supported.
- Full frontend tests, `npm run check`, `npm run build`; record results and any manual/native checks not run.

## Evidence

Implemented host/path-scoped client preferences, always-visible filled/outline workspace star controls, the adjacent starred-only directory-filter button, immutable filtering for directory/agent/flat modes, context counts and an actionable empty state. Star actions do not invoke navigation or backend mutations. Saved stars are retained across temporary catalog absence; the filter starts disabled on application launch.
