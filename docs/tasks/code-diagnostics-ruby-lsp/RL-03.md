**Goal.** ruby-lsp runs beside RuboCop for opened Ruby files.

- `languages.go`: Ruby `Live: [rubocop, ruby-lsp]`; disabling Ruby disables
  both.
- `workspace_adapters.go`: a `workspaceProviders` entry and `providerRoots`
  for `ruby-lsp`, with the same Ruby workspaces (each `Gemfile`) and skip
  lists as RuboCop.
- `live_discovery.go` and `internal/engine/code_diagnostics_local_live.go`:
  wire discovery; remote servers get it through the same path.
- Navigation routing: with both providers owning a `.rb` file,
  `navigationRoute` picks ruby-lsp; RuboCop's diagnostics are unchanged.

**Likely files.** `languages.go`, `workspace_adapters.go`,
`live_discovery.go`, `internal/engine/code_diagnostics_local_live.go`, their
tests.

**Done when.** Synthetic tests: both providers listed for a Ruby project, one
ruby-lsp server per nested `Gemfile`, routing picks ruby-lsp, RuboCop
findings still arrive, the disabled language stops both.

**Outcome (2026-11-07).** Ruby's language entry is
`Live: [rubocop, ruby-lsp]`; `workspace_adapters.go` has a
`workspaceProviders` entry for `ruby-lsp` (configs `Gemfile`,
`Gemfile.lock`) and `providerRoots` gives it RuboCop's Ruby workspaces, so
each `Gemfile` with Ruby sources gets its own ruby-lsp server with its own
`BUNDLE_GEMFILE`. The engine and remote servers already pass the Ruby
environment through `DiscoverLocalLive`; nothing changed there. Differences
from the brief:

- **Shared ownership needed a rule.** `DiscoveryDocuments` let only Ruff and
  Pyright own one document together; any other overlap resolved to no owner.
  The rule is now a small table, `sharedPairs` in `live_discovery.go`:
  Python's Ruff + Pyright and Ruby's RuboCop + ruby-lsp, each only in its own
  language, in either order. The plan's "navigationRoute already picks the
  owner" was true only once both own the file.
- ruby-lsp's approval files are Bundler's (`Gemfile`, `Gemfile.lock`, the
  version file); `.rubocop.yml` stays RuboCop's. A dropped `Gemfile` without
  sources (a Jekyll `docs/`) is bound to the root workspace, as for RuboCop.
- Provider counts in the live-discovery tests went from 7 to 8.
