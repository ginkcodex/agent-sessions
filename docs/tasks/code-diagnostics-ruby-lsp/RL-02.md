**Goal.** `DiscoverRubyLsp` returns a plan whose `ServerConfig` starts the
server as the plan says.

- `ruby_lsp.go` (new): `DiscoverRubyLsp(root, reviewedPath, env)` and its
  per-workspace form, reusing RuboCop's Ruby resolution and project markers;
  `RubyLspPlan` with `Availability`, `Version`, `RubyVersion`, `Projects`,
  `Server`, `Provider`.
- The wrapper as a Go constant: binary standard streams, `$LOAD_PATH.unshift`
  of `ARGV[0]`, `require "ruby_lsp/internal"`, the `load_addons` check (exit
  3 with a fixed message), the no-op prepend, `$> = $stderr`,
  `RubyLsp::Server.new.start`. argv `<ruby> -e <wrapper> <gem>/lib`.
- Environment exactly as the plan: `HOME`, `PATH`, `GEM_HOME`/`GEM_PATH`,
  `BUNDLE_GEMFILE=<workspace>/Gemfile`, `BUNDLE_FROZEN=true`.
- `InitializationOptions`: `enabledFeatures` (every non-navigation feature
  `false`), `linters: []`, `formatter: "none"`.
- Approval inputs and policy as the plan; the wrapper text and options are
  part of the policy. Notice text from the plan.
- Exit code 3 at start maps to `unsupported` ("ruby-lsp <v> is not
  compatible with this app").
