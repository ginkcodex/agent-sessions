server as the plan says.

  of `ARGV[0]`, `require "ruby_lsp/internal"`, the `load_addons` check (exit

- Environment exactly as the plan: `HOME`, `PATH`, `GEM_HOME`/`GEM_PATH`,
  `BUNDLE_GEMFILE=<workspace>/Gemfile`, `BUNDLE_FROZEN=true`.

- Approval inputs and policy as the plan; the wrapper text and options are

- Exit code 3 at start maps to `unsupported` ("ruby-lsp <v> is not
  compatible with this app").

Differences from the brief:

- **Incompatible versions are found at discovery.** `findRubyLsp` reads
  `lib/ruby_lsp/server.rb` (bounded, inside the gem) and requires
  `class Server` and `def load_addons`; otherwise the state is
  `incompatible` → `unsupported`, "ruby-lsp <v> is not compatible with this
  app: the app cannot start it without add-ons." `server.rb` is bound into
  approval as a third toolchain file.
- **Exit 3 still maps at start**, for a gem changed after discovery: a new
  `ServerConfig.ExitFailures` (adapter-owned text per exit code) replaces the
  generic "Language server exited" with an `unsupported` failure when the
  process exited with that code. Display only, so not in the policy.
- **The wrapper is bound through argv**: `Command.Policy` already serializes
  the arguments, so no separate hash is added; a test checks that changing
  the wrapper or the options changes the policy. The adapter policy with the
  options is about 600 bytes, under the 2048-byte bound.
- **`documentSymbols` stays enabled** (with `definition` and `hover`, set
  explicitly): RL-04 sends `textDocument/documentSymbol` to re-index drafts,
  and the server then advertises the method it is asked for. The other 15
  features RL-00 found are `false`.
- **Notices.** The Gemfile sentence is added only when the workspace has a
  `Gemfile`. A Ruby below 2.7 rejected during resolution now names the
  tool's own floor ("version 3.0 or newer" for ruby-lsp); the shared helper
  takes the minimum Ruby as a parameter.
- More messages than planned: a missing dependency names the gem and
  `gem install <name>`; a locked ruby-lsp that is too old says
  `bundle update ruby-lsp`.
- Not wired yet: the language table, the workspace scan and the engine
  (RL-03).
