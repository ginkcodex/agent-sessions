# RL-04 — Index freshness: saved files and drafts

- **Status:** ✅ Done
- **Estimate:** 4 h
- **Depends on:** RL-03
- **Plan:** [code-diagnostics-ruby-lsp.md](../../plan/code-diagnostics-ruby-lsp.md)

**Goal.** Definitions added in saved files and in open drafts become
navigable.

- `live_owner.go` `WatchedFiles`: forward saved `.rb` transitions to the
  ruby-lsp session too (today gopls only), through the existing contained
  `SessionDocuments.WatchedFiles`.
- A per-adapter "re-index before navigation" hook in the session: for
  ruby-lsp, before sending a navigation request, send one
  `textDocument/documentSymbol` for each open Ruby document changed since its
  last re-index, and discard the result. Bounded (at most the open documents
  of that session) and skipped when nothing changed.
- The hook is off for every other adapter.

**Likely files.** `internal/codediagnostics/live_owner.go`, `lsp_session.go`
or `lsp_documents.go`, `ruby_lsp.go`, tests.

**Done when.** Synthetic tests with a fake server see the watched-file
notification for `.rb` saves, see `documentSymbol` before a navigation
request after a change and not otherwise, and no change for other adapters.
The real behavior is checked in RL-07.

**Outcome (2026-11-07).**

- **Drafts.** `ServerConfig.Reindex` (not in the policy, like
  `ExitFailures`) names a read-only request; ruby-lsp's is
  `textDocument/documentSymbol`, empty for every other adapter. The session
  marks a URI on `didOpen` and `didChange` (open lifecycles only) and
  forgets it on `didClose`. `SessionDocuments.Navigate` first sends the
  request once per marked URI, in URI order, under the navigation deadline,
  and discards the answers. An error answer unmarks the document and
  navigation goes on; an unanswered request (canceled, timed out,
  disconnected) leaves the rest marked and fails the navigation as before.
- **Saved files.** `LiveDocuments.WatchedFiles` now forwards by provider, not
  only by extension: `watchedFileProviders` gives gopls the `.go` paths and
  ruby-lsp the Ruby paths; RuboCop and every other server get none (both
  Ruby providers cover `.rb`, so an extension filter alone would have sent
  RuboCop the changes too). `SessionDocuments.WatchedFiles` keeps its
  behavior; the filtered path is `watchedFiles(…, accept)`.
- **Not done here, now [RL-10](RL-10.md):** the only project watcher is the
  Go syntax check's, started for projects with Go sources and approved
  `go-syntax`. In a Ruby-only project, no saved-file transitions reach
  ruby-lsp yet; a changed closed file is re-indexed only once it is opened.
