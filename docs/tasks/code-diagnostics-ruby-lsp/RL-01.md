# RL-01 — Find ruby-lsp

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** RL-00
- **Plan:** [code-diagnostics-ruby-lsp.md](../../plan/code-diagnostics-ruby-lsp.md)

**Goal.** Find an installed ruby-lsp and its dependencies as files, without
running anything.

- `ruby_gems.go`: `findRubyLsp(workspace, lock, …, rt, env)`. If
  `Gemfile.lock` lists `ruby-lsp`, that version is required, looked up in
  `BUNDLE_PATH`, the user and the interpreter gem directories; otherwise the
  newest `ruby-lsp` in the user or interpreter gem directory.
- A candidate needs `gems/ruby-lsp-<v>/lib/ruby_lsp/internal.rb` and
  `specifications/ruby-lsp-<v>.gemspec` as regular files within its gem
  directory (the RuboCop check needs `exe/`; generalize `findGem`/`newestGem`
  to take the required entry file).
- Runtime dependencies read from the gemspec's `add_runtime_dependency` lines
  (bounded read; names only) must exist by name in the same directories or as
  default gems (`specifications/default/<name>-<v>.gemspec`).
- Version below 0.26 or Ruby below 3.0: `unsupported` with the plan's
  wording. None found: `missingTool`, "ruby-lsp is not installed. Run gem
  install ruby-lsp, then refresh." A locked version that is not installed:
  "ruby-lsp <v> from Gemfile.lock is not installed. Run bundle install, then
  refresh."

**Likely files.** `internal/codediagnostics/ruby_gems.go`,
`ruby_gems_test.go`.

**Done when.** Synthetic tests cover locked and newest selection, a locked
version not installed, a missing dependency, a dependency only as a default
gem, the version floor, a malformed gemspec and links leaving the gem
directory.
