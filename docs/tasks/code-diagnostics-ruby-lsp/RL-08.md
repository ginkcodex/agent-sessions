# RL-08 — Indexing progress state (optional)

- **Status:** ⬜ Not started
- **Estimate:** 4 h
- **Depends on:** RL-07
- **Plan:** [code-diagnostics-ruby-lsp.md](../../plan/code-diagnostics-ruby-lsp.md)

**Goal.** Tell the user when Ruby navigation is waiting for the index,
instead of an empty answer.

- A `ServerConfig` flag that advertises `window.workDoneProgress` and answers
  `window/workDoneProgress/create` with `null`, bound into the policy; on for
  ruby-lsp only.
- Track the `indexing-progress` token's `begin`/`end`; a navigation request
  before `end` reports an "indexing" state the frontend shows.
- First measure with the real server what the progress sequence looks like
  (not observed in RL-00).

**Needs** the user's approval to run the downloaded ruby-lsp gem.

**Done when.** Synthetic tests for the flag, the answer to `create`, and the
state; one real run recorded in Evidence. Not required for the first
release.
