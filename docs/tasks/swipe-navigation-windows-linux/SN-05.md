# SN-05 — Swipes in a row: split the wheel stream into strokes

- **Status:** ✅ Done
- **Estimate:** 2 h
- **Depends on:** SN-02
- **Plan:** [swipe-navigation-windows-linux.md](../../plan/swipe-navigation-windows-linux.md)

## Scope

Found in SN-03: on Windows a swipe works, but swipes in a row do not each
navigate. Without a phase, a gesture ended only after a 200 ms pause, and a
gesture swipes once. The touchpad's momentum after the fingers lift, or a
quick lift and touch, keeps the stream going, so the next swipe joined the
last one and was dropped.

`SwipeGuard` ends a stroke after the pause as before, or when the fingers
come back: the speed (`|deltaX| + |deltaY|`) fell to half its peak or less,
then rose (at least 1.5 × that low + 3 px) for two events in a row. Each
stroke swipes at most once and has its own "scrolled" flag. Momentum only
slows down, so it never starts a stroke; one swipe that keeps speeding up
stays one stroke.

## Acceptance criteria and tests

- Unit test: swipes started in the last one's momentum each navigate;
  momentum longer than a swipe, a long swipe that speeds up and a single
  coalesced spike do not swipe twice; a reversal during momentum goes the
  other way; a stroke that scrolled does not block the next stroke, also
  for the native `nav:swipe`.
- `npm test` and `npm run check` pass.

## Evidence

- `frontend/src/lib/swipeNavigation.ts`: `risesAgain` tracks the peak, the
  low since it, and the events rising from that low (`STROKE_DECAY` 0.5,
  `STROKE_RISE_EVENTS` 2; zero-speed events are skipped). `startStroke`
  resets the scrolled flag and the detector. It runs on all platforms, so
  on macOS and Linux a new stroke also clears the last one's scroll before
  the native `nav:swipe` is checked.
- `TECH-NOTES.md`: the Windows note describes strokes.
- Test (`search.test.mjs`): `swipes in a row each navigate, even when the
  next starts in the last one's momentum`, with the cases above. The
  existing swipe tests pass unchanged.
- `npm test`: 1142 pass, 0 fail (1 skipped, as before). `npm run check`:
  0 errors, 0 warnings.
- Not checked: real touchpad streams; the 0.5 decay and 2-event rise are
  guesses until SN-03 is repeated with this build.
