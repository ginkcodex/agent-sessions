# SN-03 — Check on Windows

- **Status:** 🟡 Partial (swipes work with SN-09; sideways scrolling and the mouse not reported)
- **Estimate:** 1 h
- **Depends on:** SN-02, SN-09
- **Plan:** [swipe-navigation-windows-linux.md](../../plan/swipe-navigation-windows-linux.md)

## Scope

On a Windows test build, with a Precision Touchpad and a mouse, walk the
plan's Windows release criteria:

- swipe right and left in the session list and in Go to File;
- scroll a long code line, a wide transcript block and a long text field
  sideways, then swipe again at the edge;
- scroll with the mouse wheel, Shift+wheel and (if there is one) a tilt or
  thumb wheel; press the side buttons.

Tune the distance, event count and wheel step if a swipe is too easy or
too hard, or if a mouse triggers it.

## Acceptance criteria and tests

- Each criterion observed, or listed as not checked.
