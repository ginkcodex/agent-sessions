# SN-10 — Frontend: Windows swipes come as nav:swipe

- **Status:** ✅ Done
- **Estimate:** 2 h
- **Depends on:** SN-09
- **Plan:** [swipe-navigation-windows-linux.md](../../plan/swipe-navigation-windows-linux.md)

## Scope

With SN-09, Windows sends `nav:swipe` like macOS and Linux. The page's
wheel detector (SN-02, SN-05, SN-06, SN-08) goes: `SwipeGuard` only tracks
the wheel gesture and whether it scrolled something sideways, on every
platform, and `subscribeMouseNavigate` drops `nav:swipe` while it did.
Text fields still count as sideways scrollers.

## Likely files

`frontend/src/lib/swipeNavigation.ts`, `frontend/src/lib/api.ts`,
`frontend/test/search.test.mjs`, `TECH-NOTES.md`, the plan.

## Acceptance criteria and tests

- No detector left: no `onSwipe`, no `detect` flag, no wheel thresholds.
- Tests: `nav:swipe` is dropped while the gesture scrolled something and
  delivered after a pause; wheel events never navigate by themselves.
- `npm test` and `npm run check` pass.

## Evidence

- `swipeNavigation.ts`: the detector, `onSwipe`, the `detect` flag, the
  wheel thresholds and `SwipeDirection` are gone; `SwipeGuard` reads only
  `deltaX`, `ctrlKey`, `timeStamp` and `target`. `subscribeMouseNavigate`
  no longer subscribes to the guard.
- Tests (`search.test.mjs`): the Windows detector test and the SN-08 test
  are replaced by `nav:swipe is dropped while the gesture that scrolled
  goes on; wheel events alone never navigate`. The guard and
  `scrollsSideways` tests still pass unchanged.
- `npm test`: 1141 pass, 0 fail (1 skipped, as before). `npm run check`:
  0 errors, 0 warnings.
