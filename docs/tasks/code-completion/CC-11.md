# CC-11 — Pyright auto-imports from project files not opened

- **Status:** ⬜ Not started (needs a decision first)
- **Estimate:** 3 h
- **Depends on:** CC-08
- **Plan:** [code-completion.md](../../plan/code-completion.md)

## Goal

Decide whether Python completion should suggest, with an import, names from
the project's own modules that are not open, and do it if so.

## Found by

CC-09's real-server QA with Pyright 1.1.414. In `main.py`, typing
`helper_va` gave no items, though `helpers.py` beside it defines
`helper_value`. Changed for one run to `diagnosticMode: workspace` (then
reverted), Pyright offered `helper_value` with the extra edit
`from helpers import helper_value` after about 0.8 s. With `openFilesOnly`,
which `pyrightSettings` uses (`pyright_lsp.go`), Pyright does not load
files that are not open, so it has no symbols from them to import.

Auto-imports from modules Pyright has loaded do work: `DefaultDict` comes
with `from typing import DefaultDict`. Unlike Pylance, Pyright does not
index the whole standard library, so `collections.defaultdict` is not
offered until `collections` is loaded. That is upstream behaviour, and this
task does not change it.

## Options

1. `diagnosticMode: workspace`. Pyright then checks every file in the
   project. That costs CPU and memory on large projects, and it publishes
   diagnostics for files that are not open. The Manager would have to drop
   those, since Code checks covers opened documents only. The fingerprint
   changes, and the grant carries over as in CC-08.
2. Keep `openFilesOnly` and say in Code checks that Python suggests imports
   only from modules already loaded.
3. Another Pyright setting, if one loads files for auto-import without
   checking them. None is known; check the Pyright docs first.

## Done when

- The chosen option is recorded in the plan. If it is option 1, the QA
  probe `pyright project symbol, imported` passes, with no diagnostics shown
  for files that are not open, and a large project (thousands of `.py`
  files) is measured for start time and memory. Remove the probe's `CC-11`
  marker.
