## Scope

- **Blocker wording.** `completionBlocker` returns "Code suggestions are not
  available for this host." whenever completion is off, before
  `navigationBlocker` can say the host is disconnected, runs no language
  servers or has an older server. It passes `completionCapable` as the
  feature flag instead. The text is not shown in the UI today; callers use
  it as a flag, and the flag does not change.
- **Flush.** `flush` queues pending typing in its first step. When the text
  is refused (`limitExceeded`, `invalidArgument`), the document fails
  before the change listener exists, so the request waits its whole bound.
  The step checks the failure again after queueing.
- **Mock imports.** The demo backend resolves a name declared in another
  open document to a JS import, whatever the language, so a Go or Python
  file gets `import { x } from './y';`. Only JS and TS files get it.
- **Names.** The preference's storage key is `SUGGEST_WHILE_TYPING_KEY`,
  not `SUGGEST_KEY`, the name of the key binding in `editorKeys.ts`.
- **Tests.**
  - The settings test escapes only the first `+` of the shortcut label in
    a regex; it compares plain text.
  - The Chrome harness kills Chrome with SIGKILL after 5 s but does not
    wait for it to exit before removing its profile folder.
