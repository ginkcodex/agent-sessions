# CC-09 — Real-server and SSH QA

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** CC-07, CC-08
- **Plan:** [code-completion.md](../../plan/code-completion.md)

## Goal

Check completion against real language servers and a real remote host, and
record what was and was not checked.

## Scope

- For each server: gopls, Pyright, vtsls (TS and JS), rust-analyzer, Svelte,
  Intelephense, JDT LS, ruby-lsp. Check member completion after `.`,
  completion of a project symbol, an item that adds an import, a snippet
  item, item details, and filtering while typing on.
- Measure the time from keystroke to popup on a local project and on an SSH
  host, with a large TS project to exercise the item cap.
- Check keyboard behaviour in the Go to File dialog: the shortcut (Cmd+I on
  macOS, Ctrl+Space elsewhere), Tab, Enter and Escape with and without a
  popup, and IME input (Vietnamese and Japanese) not
  being disturbed by the popup.
- Native GUI checks on macOS, Windows and Linux only where they actually
  run; list the rest as not checked.

## Done when

- `## Evidence` lists each server and check with its result, the measured
  latencies, and what was not checked. Problems found become new CC tasks.
