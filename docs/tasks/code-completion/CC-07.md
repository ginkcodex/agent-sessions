# CC-07 — Snippet completions

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** CC-06
- **Plan:** [code-completion.md](../../plan/code-completion.md)

## Goal

Completions such as functions with parameters insert placeholders the user
can Tab through, as in VS Code.

## Scope

- Turn on `completionItem.snippetSupport` in `initializeParams` (a client
  capability, not in the approval policy; the golden policy test stays
  green).
- Convert LSP snippet syntax to a CodeMirror `snippet()` template:
  `$1`, `${1}`, `${1:default}`, nested placeholders, `$0`, escapes
  (`\$`, `\}`, `\\`). Choices (`${1|a,b|}`) use their first choice;
  variables (`$TM_FILENAME` and others) insert their default or nothing.
  Anything that does not parse is inserted as plain text without the
  syntax.
- Snippet items apply through the same edit mapping as CC-06; extra edits
  still apply in the same undo step.

## Done when

- A gopls or vtsls function item inserts its parameters as tab stops and
  ends at `$0`.
- Malformed snippets insert readable plain text and never throw.

## Tests

- Unit tests for the converter: every syntax form, nesting, escapes,
  choices, variables, malformed input, UTF-16 text.
- Editor test: accepting a snippet item, Tab through stops, undo.
- Go test that `initializeParams` declares snippet support and the policy
  is unchanged.
