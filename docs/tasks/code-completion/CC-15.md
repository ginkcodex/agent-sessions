## Scope

- **Headless Chrome harness** (`file-editor-chrome.test.mjs`):
  - a bad `AS_TEST_CHROME` path, a failed DevTools connection or a page
    that never loads fails at once with the reason, and Chrome is killed;
  - pending DevTools calls fail when the socket closes, and each has a
    timeout;
  - the static server serves only files inside its folder;
  - the first test uses `caretToEnd`;
  - waits poll for the expected state with a deadline instead of fixed
    sleeps, and the resolve race is held by a gate the test opens after
    its keystroke.
- **jsdom and store tests:**
  - the capability sentinel in `live-lifecycle-integration.test.mjs`
    counts calls, since `complete()` swallows the throw;
  - `assert.equal` for a length;
  - the keymap order check finds the Tab accept binding by key;
  - the snippet test's click-elsewhere step asserts its result.
- **Settings:** the test renders the checked state, and a new one checks
  that `PreferencesStore` turns the setting on by default and reads it
  back off.
