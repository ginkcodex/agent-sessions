## Scope

- **Mirrors.** `snippetText` writes each stop's own parts, so a mirror (a
  bare `$1` after `${1:name}`) adds nothing: `${1:name} = $1` becomes
  `name = `. The plain text goes in when there is no template (more than
  two escapes on a line), after typing while an import resolved, or when
  the fields fail. A mirror takes its stop's first placeholder text, as
  `snippetTemplate` does.
- **Read-only.** The review said an accept that waits for its import
  (`acceptResolving`) checks the tab and path when it settles, not whether
  the editor became read-only meanwhile (`disabled`: a file action is busy
  or the app quits), and `EditorState.readOnly` does not stop a
  programmatic dispatch. Checked: a read-only editor has no suggestion
  extensions, so its pending pick goes with them and nothing goes in. A
  test pins this, and the code says why.
- **Readability.** The nested ternary that maps asked offsets in
  `completionChanges` becomes if/return branches, as in CC-14.

## Done when

- `${1:name} = $1` is `name = name` in plain text.
- A test shows an awaited pick does not go in once the editor is disabled.
