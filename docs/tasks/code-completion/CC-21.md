## Scope

- **An awaited item at an empty range goes before what was typed.** An item
  accepted right after a trigger character (`obj.`) replaces nothing. While
  its import is awaited, its range is mapped with `from` to the right and
  `to` to the left; on an empty range both end up after typed text, so
  `obj.` + accept `foo` + `x` gives `obj.xfoo`. An empty range is mapped to
  the left, so the item goes before the typed text: `obj.foox`.
- **The language's own sources run once per query.** `languageLabels` runs
  each language source that answers at once again, beside CodeMirror's own
  run, to leave its names out of the document's words. The labels are read
  from a single run instead, shared with CodeMirror's.

## Done when

- `obj.` + accept + `x` during the wait gives `obj.foox`.
- Per query, each language source runs once.

## Tests

- Frontend (jsdom): the empty-range case, with typing during the wait;

  stay out of the words.
