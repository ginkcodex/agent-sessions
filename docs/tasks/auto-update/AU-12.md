# AU-12 — Windows code signing in CI

- **Status:** ⬜ Not started
- **Estimate:** 3 h
- **Depends on:** —
- **Plan:** [auto-update.md](../../plan/auto-update.md)

## Scope

Sign `agent-sessions.exe`, the MSI and `_setup.exe` with Azure Trusted
Signing (or another Authenticode service the maintainer picks) in the
release workflow, and check the signatures in
`packaging/windows/verify-packages.sh`. Not needed for auto-update; it
removes the SmartScreen warning on first install.

## Likely files

`.github/workflows/release.yml`, `packaging/windows/verify-packages.sh`,
`Makefile`.

## Acceptance criteria and tests

- The signatures verify (`osslsigncode verify` on Linux).
- Without the secrets, manual runs build unsigned with a warning.
