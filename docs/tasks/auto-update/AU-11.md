## Scope

On Windows, with MSI installs of N and N+1 and a local feed:

- Restart now; Later then quit; a CLI process from the install folder
  still running.
- A failure injected after the removal: N is installed again.
- Refusals: bad signature, wrong hash, a test build in an
  `agent-sessions-launchN` folder.
- Remote servers redeploy to WSL after the update.
- Check by hand: Settings › Check for updates (up to date, a release found,
  offline).
