# AU-10 — Windows: apply on restart or quit

- **Status:** ⬜ Not started
- **Estimate:** 4 h
- **Depends on:** AU-04, AU-09
- **Plan:** [auto-update.md](../../plan/auto-update.md)

## Scope

- `--apply-update <ready folder>` as on macOS, from a copy in `%TEMP%`.
- Wait until no process runs from the install folder (app, CLI, terminals
  started from it), up to a time limit.
- Remove the installed product, then install the new MSI, both `/quiet
  /norestart` with verbose logs in the updates folder (setup's arguments).
- If the install fails after the removal, install the rollback MSI. Start
  whichever version is installed.
