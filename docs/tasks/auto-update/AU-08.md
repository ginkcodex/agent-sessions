## Scope

On a Mac, with Developer ID signed builds N and N+1 and a local feed
(`AGENT_SESSIONS_UPDATE_URL`, a QA key):

- Restart now; Later then quit; app in `/Applications` and in
  `~/Applications`.
- A running terminal: Restart now asks before ending it.
- Refusals: bad signature, wrong hash, ad-hoc signed app, unwritable folder,
  app run from the `.dmg`.
- Granted permissions (notifications, Apple Events) survive the update.
- Check by hand: Settings › Check for updates and the app menu's Check for
  Updates… (up to date, a release found, offline, with only About open).
