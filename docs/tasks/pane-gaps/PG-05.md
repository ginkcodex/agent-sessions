# PG-05 — Pane outlines in light mode

- **Status:** ✅ Done
- **Estimate:** 0.5 h

- **Plan:** [pane-gaps.md](../../plan/pane-gaps.md)

## Scope

In light mode the pane cards had no visible outline. Their border used
`--border-color` (rgba(15, 23, 42, 0.1)), which on the white card renders
about #e8e8ea, lighter than the #dde2e9 gutter, so the edge blended in. Give
the cards their own `--pane-border` token: darker than the gutter in light
mode, unchanged in dark mode.

## Likely files

- `frontend/src/style.css`
- `frontend/src/App.svelte`
- `frontend/test/splitter.test.mjs`

## Acceptance criteria and tests

- Light mode: the sidebar, session list, transcript and terminal panel cards
  show a 1px outline darker than the gutter.
- Dark mode looks as before (`--pane-border` is `var(--border-color)`).
- A test pins both themes' values and that the cards use `--pane-border`.
