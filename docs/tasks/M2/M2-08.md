## Task

Push backend changes to the UI (`runtime.EventsEmit` with the `OnStartup` ctx, subscribed through `api.ts`), reactively updating tree counts, list rows and the header

## Done when

UI updates without manual refresh. A coalesced (100 ms) `catalog:changed` event carries changed/removed refs; the UI reloads the tree in the background, the list only when affected, and the header in place.
