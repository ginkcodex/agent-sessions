# GR-02 — Check on Linux desktops

- **Status:** 🟡 Partial (AMD Wayland only; NVIDIA and X11 not checked)
- **Estimate:** 1 h
- **Depends on:** GR-01
- **Plan:** [linux-gpu-rendering.md](../../plan/linux-gpu-rendering.md)

## Scope

Run a build with GR-01 on:

- the AMD laptop at 1.5×: the window draws, scrolling and animations are
  smooth, the idle main thread is low;
- an NVIDIA machine (proprietary driver): the window is not blank, and
  `WEBKIT_DISABLE_DMABUF_RENDERER` is `1` in the app's environment
  (`/proc/<pid>/environ`), set by Wails;
- X11, if available.

## Acceptance criteria and tests

- Each case observed, or listed as not checked.

## Evidence

- 2026-11-07, the user on the AMD laptop (GNOME Wayland, 1.5×) ran 1.3.1
  with `WEBKIT_DISABLE_DMABUF_RENDERER=0`, the renderer GR-01 now picks. The
  window draws, and it "looks a bit better". Measured: main thread ~1 %
  idle, ~22 % while in use (web process ~37 %).
- Not checked: the GR-01 build itself on screen, NVIDIA, X11.
