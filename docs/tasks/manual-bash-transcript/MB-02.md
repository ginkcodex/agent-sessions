# MB-02 — Render readable manual Bash command and output cards

- **Status:** ✅ Done
- **Estimate:** 4 h
- **Depends on:** MB-01
- **Plan:** [manual-bash-transcript.md](../../plan/manual-bash-transcript.md)

## Scope

Render dedicated Claude manual Bash messages as terminal-style transcript cards, keeping command/output records independent for paging/live updates. Label manual commands, stdout and stderr; omit empty streams; preserve whitespace, support copying, and bound large output. Use safe text rendering and existing theme/font tokens. Record actual checks and manual QA limitations.

## Likely files

Frontend transcript/message components, presentation helpers, styles and frontend regression tests.

## Acceptance criteria

- No protocol wrappers in recognized command/output cards.
- Commands and output are monospace, whitespace-preserving and copyable.
- Empty stdout/stderr and stderr-only output work without falsely claiming a failed exit status.
- HTML-like output is inert text; quoted/malformed wrappers and other providers' messages remain normal messages.
- Large output is bounded and inspectable; existing chat/activity filtering, pagination and message IDs continue to work.

## Tests

Parser/presentation and component tests covering screenshot-shaped content, both streams, empty streams, HTML-like content, multiline and long output, malformed/literal wrappers and provider gating. Frontend full tests, type check/build; native light/dark, remote and clipboard manual checks recorded as run or not run.
