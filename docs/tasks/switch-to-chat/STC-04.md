# STC-04 — QA in the desktop app

- **Status:** ⬜ Not started
- **Estimate:** 1 h
- **Depends on:** STC-02, STC-03

## Scope

Manual pass in the desktop app (local, and a WSL or SSH host if handy):
the item's presence and reasons, the working and waiting questions, the
switch with an idle tab and a working one, a split tab (siblings stay),
and the chat that results (continuity of the conversation).

## Acceptance criteria and tests

Record what was run and what was not in Evidence. Planned QA is not a
pass.
