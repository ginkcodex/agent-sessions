# CA-05 — Attach from the composer

- **Status:** ✅ Done
- **Estimate:** 4 h
- **Depends on:** CA-04
- **Plan:** [chat-attachments.md](../../plan/chat-attachments.md)

## Scope

- Types and API: `ChatAttachment`, `promptCapabilities` on `ChatState`,
  `chatPrompt(chatId, text, attachments)`, `chatPickAttachments`,
  `chatAttachFiles`, `chatAttachImage`; the Wails binding and the mock.
- Composer:
  - a + button at the left of the toolbar ("Attach images or files"),
    hidden without `promptCapabilities`, disabled while starting;
  - chips above the text box: an image's thumbnail or a file icon, the name,
    and a remove button;
  - Send with text, attachments or both; a failed send gives both back;
  - drops on the composer (`data-file-drop-target="chat"`) attach the files;
    the terminal panel ignores them;
  - pasting an image attaches it;
  - skipped files and errors show as a toast.
- Store and live tail: the prompt keeps its attachments; the user item shows
  them as file parts (an image from the data the window holds).

## Acceptance criteria

- The + button, chips and their removal have accessible names.
- The button is hidden for a chat without `promptCapabilities`.
- A prompt with only attachments is sent and shows in the live tail.

## Tests

- SSR and store tests for the above; `npm test`, `npm run check`,
  `npm run build`; a headless Chrome screenshot of the composer with chips.

## Evidence

What was done:

- `types.ts`, `api.ts`, the Wails binding and the mock (`mockAttachFiles`,
  `mockAttachImage`, a made-up PNG; the mock agent's reply counts the files
  and its saved user message carries them as file parts).
- `chat.ts`: `addAttachments` (images refused for an agent that takes none,
  the 10-file limit), `skippedToast` and `canSendPrompt`, kept out of the
  component so they are tested directly; `tailMessages` turns the user
  item's files into file parts.
- `chatTail.ts`: `beginTurn` keeps the prompt's files; a prompt of only
  files is dropped once its turn is saved.
- `ChatComposer.svelte`: the + button, chips (new `AttachmentChips.svelte`),
  send with files, the failed-send restore, drop target and paste.
  `TerminalPanel.svelte` leaves drops on the chat alone. `ImagePart.svelte`
  shows an image from `FileRef.data` without a fetch.
