# CA-04 — App bindings for attaching files

- **Status:** ✅ Done
- **Estimate:** 3 h
- **Depends on:** CA-03
- **Plan:** [chat-attachments.md](../../plan/chat-attachments.md)

## Scope

- `App.ChatPrompt(chatID, text, attachments)`.
- `App.ChatPickAttachments(chatID)`: a multi-select open dialog (in the
  chat's directory for a local chat); returns the prepared attachments and
  the skipped files with reasons. Cancel returns nothing.
- `App.ChatAttachFiles(paths)`: the same for dropped files.
- `App.ChatAttachImage(name, data)`: a pasted image in base64.
- `app.Desktop.OpenFiles` and its Wails adapter
  (`PromptForMultipleSelection`).
- `APP_METHODS` and the binding contract.

## Likely files

- `internal/app/chat.go`, `internal/app/desktop.go`, `internal/app/chat_test.go`
- `cmd/agent-sessions/desktop_v3.go`
- `frontend/src/lib/appBinding.ts`

## Acceptance criteria

- Several files picked at once; files that cannot be attached are skipped
  with a reason while the rest attach.
- Without a desktop the picker returns `ErrDesktopUnavailable`.

## Tests

- `go test -race ./internal/app/... ./cmd/...`, with a fake desktop dialog.

## Evidence

- Done:
  - `App.ChatPrompt(chatID, text, attachments)`.

    chat on this computer and in the home directory otherwise, and returns
