## Scope

- A Git scope for one discovery walk (`internal/codediagnostics`, new file):
  created with the authorized root, it asks `files.IgnoredDirectories` once
  at the root. `skip(rel)` is asked for each folder the walk would enter:
  a folder with its own `.git` marker (directory or regular file, read with
  `os.Root.Lstat`, never a symlink) is entered and its own Git is asked,
  its answer added under that prefix; otherwise a folder Git ignores is
  skipped. At most 16 Git calls and 5 s per scope; when Git is unknown it
  skips nothing.
- A shared entry order: files first, then folders, each by name.
- `discoverGoWorkspace` (`go_lsp.go`) and `GoVetPlan.discover`
  (`go_vet.go`) use the scope and the order. Ignored folders are not
  partial.

## Acceptance criteria

- A root `go.mod` is found when folders that sort before it hold more than
  the 4096-entry budget (both gopls and go vet).
- A module inside an ignored folder is not found; a module inside an ignored
  folder that is its own repository is found, and that repository's own
  ignored folder is skipped.
- Without Git, or when the root is ignored by an outer repository, the
  result is the same as before this change.
- Existing gopls and go vet tests pass unchanged, or the change of each is
  explained in Evidence.

## Evidence

  `files.IgnoredDirectories` at the root when created; `skip(r, rel)` enters
  a folder with its own `.git` marker (directory or regular file, via
  `os.Root.Lstat`) and asks its Git, else skips a folder its repository
  ignores. At most 16 Git calls and 5 s per scope. `filesFirst` orders a
  folder's entries files first, then folders, each by name.

  asked after the existing name rules, only for folders the walk would
