## Scope

The Git scope and the files-first order from IS-02 in:

- `discoverProjectDirs` (`ts_lsp.go`; TypeScript, Pyright, Ruff, RuboCop);
- `scanLiveWorkspaces` (`workspace_adapters.go`);
- `walkContained` (`svelte.go`, svelte-check);
- `discoverSveltePackages` (`svelte_lsp.go`).

Where a folder's own decision is made after its loop (`discoverProjectDirs`,
`discoverSveltePackages`), running out of budget ends the loop instead of
returning, so the folder still records its markers, and no folder is read
once the budget is spent. The name rules, including the `.venv`/`venv`
`pyvenv.cfg` check, stay ahead of the scope.

## Likely files

`ts_lsp.go`, `workspace_adapters.go`, `svelte.go`, `svelte_lsp.go` and their

## Acceptance criteria

- Each walk skips an ignored folder, without partial, and walks an ignored
  nested repository.
- A root `package.json` / `svelte.config.js` is found when folders sorting
  before it exceed the budget.
- A Python project's `.venv` is still recognized when Git ignores it.
- Existing tests pass unchanged, or the change of each is explained in
  Evidence.
