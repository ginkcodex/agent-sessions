## Scope

- `IgnoredDirectories(ctx, dir) ([]string, bool)` in `internal/files`: runs
  `git ls-files -z --others --ignored --exclude-standard --directory` in
  `dir` and returns the folder entries only, without the trailing `/`,
  slash-separated, relative to `dir`, sorted.
- `ok` is false when Git is missing, `dir` is in no worktree, Git fails or
  the context ends, or Git answers `./` (an outer repository ignores `dir`
  itself).
- Git runs with `--literal-pathspecs`, `-c core.fsmonitor=false` and
  `gitHistoryEnv()`; the caller's context bounds it.

## Likely files

## Acceptance criteria

- Ignored folders are listed; ignored single files and tracked folders are
  not.
- Called in a subfolder of a repository, paths are relative to that
  subfolder.
- Not a repository, a root ignored by its outer repository, and no `git` on
  `PATH` all return `ok == false`.
- A repository whose `.git/config` sets `core.fsmonitor` to a script: the
  script does not run.
