## Scope

Replace the shared Icon spin and AttentionDot working opacity CSS loops with discrete, visibility-gated steps. Use shared timers (8 Hz rotation, 1.25 Hz dot toggle), with no interpolation between steps. Preserve labels and status semantics; keep reduced-motion dots steady and spinners at half speed. Do not change terminal transport, renderer, cursor, input or output cadence.

## Likely files

animationVisibility.ts, Icon.svelte, AttentionDot.svelte, style.css, rendering tests and QA record.

## Acceptance criteria and tests

- Shared clocks start only for visible subscribers and stop after the last subscriber leaves; repeated callbacks do not duplicate subscriptions.
- Test class/state updates, stale observer callbacks, unmount, re-entry and missing-observer fallback.
- Test discrete rotation about the icon center, dimming, reduced motion and retained labels.
- Full frontend suite, type check, build and diff whitespace check pass.
- Compare GPU with the same native active-terminal workload; do not infer a measured improvement from source/tests.
