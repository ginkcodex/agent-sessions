## Evidence

2026-11-11: Captured an approximately 6 s Metal System Trace with the existing
app and an active coding-agent terminal (app PID 60531, WebContent 60536).
Device utilization sampled at about 67–77%. WindowServer fragment intervals
totalled about 4.456 s (roughly 71–76% in complete one-second buckets), versus
116 WebKit GPU intervals (about 19/s), using roughly 4% GPU time. Display
surface-swap buckets reached 120/s. A 4 s WebContent sample was mostly idle,
with about 148 of 2,860 main-thread samples in rendering updates.

This points to compositor-driven motion rather than continuous heavy JS or
terminal text painting. The working AttentionDot opacity loop and visible
shared Icon transform loop are candidates; neither was isolated by an A/B.
The WebKit GPU interval rate is not a direct count of xterm text repaints.
IR-06 changes these two loops while preserving terminal behavior.

Local, temporary artifacts: `/tmp/as-terminal-gpu.jQn4HD/` (trace, exported
XML and WebContent sample). They are not checked in and may be removed by
the OS. Startup attribution, isolated indicator tests and a controlled
modified-build GPU comparison remain **not run**; this task stays partial.
