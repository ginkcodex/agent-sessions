## Scope

Stop speculative CSS changes. Measure scroll ownership, dimensions and the
scrollbar lane in WebKitGTK; distinguish the real desktop data path from mock
frontend data. Compare the top and the reported appearance threshold, then row
hover. Restore original row positioning after SS-04 failed.

## Acceptance criteria and tests

- Identify actual scroll owner and whether client/scroll dimensions change on
  hover or across the threshold in the affected packaged app.
- Distinguish geometry changes from missing scrollbar paint before another fix.
- Record native engine, fixture limitations and screenshots honestly.
