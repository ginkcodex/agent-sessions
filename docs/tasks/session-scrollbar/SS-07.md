# SS-07 — Give the scroll container its own compositing layer

- **Status:** ✅ Done
- **Estimate:** 2 h
- **Depends on:** SS-06
- **Plan:** [session-scrollbar.md](../../plan/session-scrollbar.md)

## Scope

SS-06's normal-flow rows still had no visible scrollbar at the top in the
actual native desktop (Screenshot-4.png). Give the scroll container
(`.virtual-list-container`) its own compositing layer with
`transform: translateZ(0)`, then check whether it also works without SS-06, so
the fix is the smallest change.

## Likely files

- `frontend/src/lib/components/sessionlist/VirtualList.svelte`
- `frontend/test/virtual-list.test.mjs`

## Acceptance criteria and tests

Build an isolated production desktop and use native wheel scrolling down and
back up with real data. Inspect the screenshot at the top, then sweep the
native pointer across rows while capturing. Existing frontend checks and tests
must pass.

## Evidence

- **With SS-06 structure** (`/tmp/agent-sessions-scrollbar-flow`): after 22
  native wheel steps down and 26 up, the thumb is visible at the top
  (`/home/haith/Pictures/Screenshot-6.png`). Same crop of SS-06 alone
  (Screenshot-4) has no thumb.
- **On the original `HEAD` structure, `translateZ(0)` only**
  (`/tmp/agent-sessions-scrollbar-z`): same wheel round trip, the thumb is visible
  at the top (Screenshot-12). Native pointer sweep down, up and down across
  the rows, with four captures during the sweep (Screenshot-13 to -16): rows 3,
  5, 6 and 8 hovered in turn, and the thumb is visible in every frame.
- Kept the one-line fix on the original structure with a comment; SS-06 reverted.
  `frontend/test/virtual-list.test.mjs` now asserts the container keeps
  `overflow-y: auto` and `transform: translateZ(0)`.
- Side-effect check: the transform makes the container the containing block for
  `position: fixed` descendants. None exist: the count tooltip is
  `position: absolute` inside rows that were already transformed, and the
  session menu renders outside VirtualList.
- `npm run check`: 0 errors, 0 warnings. `npm test`: 1150 tests, 1149 pass,
  0 fail, 1 skipped. `npm run build`: passed. The tested binary differs from the
  final source only by the CSS comment.
- The user rebuilt with `make package-linux` on their Linux device and
  confirmed it works: the thumb is visible at the top and no longer flashes.
- Not checked: frame-accurate capture (portal screenshots can miss a flash
  shorter than one capture), other Linux distributions or WebKitGTK versions. Why WebKitGTK drops the
  scrollbar on a non-composited scroller was not traced into the engine.
