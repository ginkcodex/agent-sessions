runtime comparison, and keep Unix npm/Node fixture tests off native Windows,

## Acceptance criteria and tests

- Provider-count assertions follow the live-provider registry.

- Record native Windows/macOS CI and real-server checks as unrun unless executed.

## Evidence

- Cause, from CI runs 42552651906 (`a0925b9`) and 42561005429 (`3ca3867`):
  macOS failed `TestDiscoverLocalLiveBindsToolchainAndHoldsOtherLanguages` and
  `TestRuffDocumentResolutionThroughLocalLive` on a hard-coded count of 8
  providers (Java/PHP made it 10), and `TestPHPWrappersLocalAndReviewedRuntime`
  on an uncanonicalized `/var` temp path versus the resolved `/private/var`.
  Windows failed six PHP tests because the extensionless Unix `bin/node`
  fixture is not a Windows executable.
- Fix: count assertions use `len(LiveProviderIDs())`; the second Node prefix is
  resolved with `filepath.EvalSymlinks`; `phpHost` skips on Windows, so tests
  that need the Unix npm/Node fixture skip there. `TestPHPLanguageAndProjectDiscovery`
  still runs on Windows, and the disabled-language test no longer builds the
  fixture, so it runs on Windows too. No production code changed.
- Linux (WSL2): targeted `go test -count=1 ./internal/codediagnostics -run
  'Test(PHP|DiscoverPHP|JavaPHP|DiscoverLocalLiveBinds|RuffDocumentResolution)'`
  passed (the two count tests skip off darwin/arm64). Full
  `go test -race -count=1 ./...` passed: 42 packages ok, no failures.
- `GOOS=windows GOARCH=amd64` and `GOOS=darwin GOARCH=arm64` `go test -c
  ./internal/codediagnostics` compiled. `go tool golangci-lint run
  --new-from-rev=HEAD`: 0 issues. `gofumpt -l` and `git diff --check` clean.
- Native CI: run 42562434667 on `aadc253` passed every job (`test`,
  `linux-build`, `macos-test`, `windows-test-build`), so the macOS and Windows
  test suites now pass on real runners.
- Not run: real Intelephense/JDT LS servers on native macOS or Windows; this
  task changed only synthetic-fixture tests.
