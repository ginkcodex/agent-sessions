# NG-04 — Measure walked listings with repositories

- **Status:** ✅ Done
- **Estimate:** 1 h
- **Depends on:** NG-02
- **Plan:** [nested-repo-gitignore.md](../../plan/nested-repo-gitignore.md)

## Scope

Measure `List` on a plain root holding several repositories, before and
after NG-02: wall time, Git commands run, files, ignored files and folders
listed. Use a synthetic tree (beside `listing_bench_test.go`) and, read
only, the reporting workspace on `plgl` (`/home/haitran/Workspaces/v2`).
Record the result in `docs/perf.md`.

## Acceptance criteria

- Numbers before and after, with the commands that produced them.
- If the added time on `v2` is over 250 ms, a follow-up task to run scope
  queries ahead of the walk.

  and at the NG-03 commit. Commands and numbers in
  [`docs/perf.md`](../../perf.md#ng-04--walked-listings-with-nested-repositories-2026-11-07).
