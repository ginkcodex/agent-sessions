# SW-02 — Frontend: drop swipes that scrolled, deliver the rest

- **Status:** ✅ Done
- **Estimate:** 2 h
- **Depends on:** SW-01
- **Plan:** [swipe-navigation.md](../../plan/swipe-navigation.md)

## Scope

`frontend/src/lib/swipeNavigation.ts` watches `wheel` on the window
(passive, capture). Wheel events less than 200 ms apart form one gesture.
The gesture counts as a scroll if any of its sideways deltas could still
move the target or an ancestor that scrolls sideways (CSS overflow `auto`,
`scroll` or `overlay`, wider than it is shown, not at that edge).
`subscribeMouseNavigate` also takes `nav:swipe` and calls back unless the
current gesture is a scroll. App and Go to File need no change.

## Likely files

`frontend/src/lib/swipeNavigation.ts` (new), `frontend/src/lib/api.ts`,
`frontend/test/search.test.mjs` (beside the `nav:mouse` test) or a new test.

## Acceptance criteria and tests

- A swipe with no sideways-scrollable content under it is delivered; one
  that moved scrollable content in its direction is not, for the rest of
  that gesture; a later gesture from the edge is delivered.
- Vertical-only scrolling content does not block a swipe; a pinch
  (`ctrlKey`) is ignored; `nav:mouse` is unchanged.
- `npm test` and `npm run check` pass.

## Evidence

- `frontend/src/lib/swipeNavigation.ts` (new):
  - `scrollsSideways(target, sign)` walks up from the target. It looks for an
    element with room left in that direction (more than 1 px) that may
    scroll sideways: overflow `auto`, `scroll` or `overlay`, or the
    document's scrolling element.
  - `SwipeGuard` groups wheel events less than `SWIPE_GESTURE_GAP` (200 ms)
    apart into one gesture, and marks the gesture as a scroll once any
    sideways delta could move something. Pinches (`ctrlKey`) are ignored.
  - `windowSwipeGuard()` installs one passive capture `wheel` listener on
    first use (target from `composedPath()`, for shadow roots).
- `frontend/src/lib/api.ts`: `SWIPE_NAVIGATE_EVENT` (`nav:swipe`).
  `subscribeMouseNavigate` also delivers it, unless the guard says the
  gesture scrolled, and unsubscribes both events. App and Go to File are
  unchanged and keep their modal rules.
- Tests (`search.test.mjs`):
  - `a two-finger swipe navigates unless its gesture scrolled something
    sideways`: a free swipe, a gesture that started by scrolling (also once
    it reaches the edge, and through momentum), a new gesture from the edge,
    content that scrolls only the other way, a pinch, unguarded side
    buttons, unsubscribe.
  - `sideways scrolling counts only room left in that direction, in
    elements that scroll`: edges, a child's ancestor, `overflow: hidden`,
    the page, sign 0 and no target.
- `npm test`: 1140 pass, 0 fail (1 skipped, as before). `npm run check`:
  0 errors, 0 warnings. `npm run build` succeeds.
- Not checked: real wheel events from a trackpad in WKWebView (SW-03),
  and the timing between `nav:swipe` and the page's wheel events.
