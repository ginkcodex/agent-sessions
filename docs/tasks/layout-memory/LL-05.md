# LL-05 — Larger default navigation widths

- **Status:** ✅ Done
- **Estimate:** 0.5 h
- **Depends on:** —
- **Plan:** [layout-memory.md](../../plan/layout-memory.md)

## Scope

Found in the Windows test of LL-03: at their floors (sidebar 200 px,
session list 260 px) the columns cut off their filter placeholders, and the
defaults (260 / 340 px) were barely wider, so the headers only just fit.
Raise the defaults so each column's header shows in full with room to spare:

- `LIMITS.sidebar.default` 260 → 280 px, `LIMITS.sessionList.default`
  340 → 380 px. Floors unchanged.
- On the 1500 px first-run window the transcript keeps 840 px, above the
  800 px cap of its header need.

Defaults only apply without saved widths: a user who already dragged the
splitters keeps their widths.

## Likely files

- `frontend/src/lib/stores/preferences.svelte.ts`
- `frontend/test/splitter.test.mjs` (cases that start from the defaults)

## Acceptance criteria

- A fresh profile opens with "Filter by directory…" and "Filter sessions
  (title, prompt, cwd, model)…" shown in full.
- Saved widths, floors and equalize behave as before.

- `npm test`: 1428 tests, 1427 pass, 1 skipped (pre-existing), 0 fail. The

- Placeholder fit estimated from the user's Windows screenshot at the floors

  room for both.
